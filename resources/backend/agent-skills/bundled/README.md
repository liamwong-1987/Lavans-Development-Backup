# Bundled Agent Skills

These read-only Skill sources are required for Lavans to keep its built-in
AGENT flows portable after a clean clone. Runtime imports, confirmation
receipts, caches, generated media, and user data are intentionally excluded.

- create-product-microstory-seedance: bundled workflow source
- ecommerce-video-director-skill: instruction-only version 1.7.0
- brainstorming-obra-share: instruction-only version 1.0.0

Potentially paid tools remain unavailable until their existing executor and
approval gates are satisfied.
