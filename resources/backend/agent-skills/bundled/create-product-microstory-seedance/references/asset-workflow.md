## 最小资产包

只生成实际镜头需要的资产，避免超过 Seedance 2.0 单镜素材预算。

| 类型 | 默认数量 | 用途 |
|---|---:|---|
| 角色锚点 | 每个主角 1 张 | 锁定脸型、发型、体型、服装、配色 |
| 表情/姿态 | 每个主角 0–1 张 | 复杂反应或动作才需要 |
| 场景锚点 | 每个主场景 1 张 | 锁定空间、光线和关键物位置 |
| 产品图 | 1–2 张 | 锁定外观、包装方向、打开/使用状态 |
| 关键道具 | 0–1 张 | 道具参与反转时使用 |
| 首尾帧 | 每镜 0–2 张 | 必须固定构图或跨镜衔接时使用 |

资产台账字段：

| ID | 文件名 | 类型 | 状态 | 用途 | 镜头 | Seedance 占位符 | 生成/来源提示 | 不可变化特征 |
|---|---|---|---|---|---|---|---|---|

状态只能写“已提供 / 已生成 / 待准备 / 待生成 / 可选”。没有真实文件时不得写“已生成”。

## 角色锚点

Seedance 2.0 不使用写实真人脸部参考。默认创建原创、非真实可识别人物的 3D stylized、动画或插画角色。角色锚点写清：

- 年龄段、性别呈现、脸型、肤色、五官比例。
- 发型、发色、体型、身高关系、惯用手。
- 上衣、下装、鞋、配饰、主辅色、材质。
- 性格的可观察表达，例如站姿、目光、表情习惯。
- 正面或四分之三视角、全身可见、无遮挡、干净中性背景。

不要把不同服装、多个年龄、多个发型塞进同一锚点。角色衍生图以锚点为参考，只改变表情、姿势或机位中的一个，其余保持不变。

若需要多人，先分别生成每人的锚点，再生成同框关键帧；用身高比例、站位和服装颜色区分角色。

## 场景、产品与道具

场景锚点写清空间布局：入口方向、窗户方向、主光方向、桌椅和产品位置、可供镜头运动的路径。跨镜保持轴线和光线方向。

已有产品实拍图时：

- 优先直接作为产品参考，或进行保真编辑。
- 不重绘精确 Logo、包装文字、型号、成分表和认证标识。
- 需要透明抠图时，按系统 `imagegen` 的当前透明图片规则执行；复杂玻璃、液体、反光包装或软阴影需要 CLI fallback 时，必须先取得用户确认。

没有产品图时，只生成清楚标注的概念占位图；不要把虚构包装当作最终品牌资产。

## 图片生成提示词

每张资产使用以下结构，只填写必要字段：

```text
Use case: <stylized-concept|product-mockup|identity-preserve>
Asset type: <角色锚点/场景锚点/产品参考/首帧/尾帧>
Primary request: <核心要求>
Input images: <Image 1: 角色锚点；Image 2: 产品参考>（如有）
Scene/backdrop: <空间与背景>
Subject: <主体和可观察特征>
Style/medium: <3D stylized/动画/插画/产品摄影>
Composition/framing: <9:16、景别、机位、留白>
Lighting/mood: <光线方向与情绪>
Color palette: <稳定色彩>
Materials/textures: <服装或产品材质>
Text (verbatim): "<必须准确的文字>"
Constraints: <必须保持的特征>
Avoid: <无关人物、随机文字、水印、Logo 漂移等>
```

生成原则：

- 用户描述具体时只规范化，不擅自增加角色、道具、品牌色或剧情。
- 每个不同资产单独调用一次内置 `imagegen`。
- 编辑本地图片前先用 `view_image` 检查，再把它作为编辑目标或参考。
- 角色衍生资产重复锚点特征和不变量，迭代时一次只改一个条件。
- 图中需要精确文字时逐字引用；最终 Logo、包装文字和 CTA 仍优先放到后期。

## 本地保存规范

使用项目目录：

```text
assets/
  characters/
  scenes/
  products/
  props/
  keyframes/
```

文件名使用小写英文、数字和连字符，例如：

- `char-01-anchor.png`
- `char-01-expression-shock.png`
- `scene-01-office-anchor.png`
- `product-01-front.png`
- `s03-first-frame.png`
- `s03-last-frame.png`

内置图片生成完成后，把选中成品从默认生成位置复制到项目目录。目标存在时创建 `-v2`、`-v3`，除非用户明确要求替换。记录原始生成路径、最终路径、最终提示词和使用镜头。

## 资产验收

逐张检查：

- 角色：脸型、发型、体型、服装、配色和配饰稳定。
- 场景：空间布局、光源方向、时间和关键物位置可连续。
- 产品：轮廓、颜色、材质、Logo 方向、开合与使用状态正确。
- 构图：符合 9:16，主体完整，为动作和字幕留出空间。
- 安全：无可识别真人脸参考、第三方水印、随机品牌或文字。
- 文件：能打开，路径存在，台账状态与实际一致。

不合格时只针对一个失败点重生成，并保留旧文件为版本，不覆盖。
