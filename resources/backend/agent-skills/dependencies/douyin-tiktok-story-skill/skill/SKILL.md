# 抖音达人剧情创作

## 本地运行

首次使用运行 `python scripts/local_search.py status`。必须返回 `ok: true`、`network_used: false`。素材只存在 `assets/douyin-story.sqlite3`，不联网、不上传用户文本。

## 强制检索

任何选题、构思、大纲、正文、植入、改写、诊断或润色任务先用抽象查询检索：

```bash
python scripts/local_search.py search "校园 师生误会 前三秒冲突 反转喜剧" --top-k 6
```

项目级任务执行两次互补检索：一次检索题材与关系，一次检索钩子、节奏或植入方式。不要把未公开姓名、完整用户原文或商业秘密写进查询。

## 机制提炼

只提炼：前三秒动作或信息差；人物关系、权力差与旧账；目标、阻碍、升级、反转和回扣；台词长度、抢话节奏和角色语言功能；产品进入剧情的触发点、使用动作和利益点证明；少场景、少角色、低成本拍法；评论问题、循环结尾或系列追更口。

不得复用源脚本中的专有姓名、品牌组合、标志性台词、完整事件链、独特道具组合或连续表达。单一源脚本最多贡献一个局部机制；成稿至少重组三类机制并更换人物关系、场景、道具和反转顺序。

## 任务模式

- 选题：输出6—10个方向，每个含前三秒、关系冲突、升级、反转、拍摄条件和结尾钩子。
- 大纲：按时间段或场次输出钩子—升级—转折—植入—回扣。
- 正文：输出可拍摄动作、人物台词、字幕、音效和时长估算。
- 品牌植入：先保证剧情目标成立，再让产品以解决阻碍、暴露关系或触发反转的方式进入。
- 诊断：优先修复前三秒、人物目标、冲突升级、植入生硬和结尾泄气。
- 改写：保留用户指定事实，重做薄弱机制，不擅自替换核心卖点。

## 抖音节奏检查

- 0—3秒出现可见动作、异常、冲突或高价值信息；
- 5—15秒明确人物目标和阻碍；
- 每8—15秒至少发生一次关系变化、信息增量或行动升级；
- 产品卖点用动作与结果证明，不连续口播参数；
- 对白短、可演、可剪，避免解释人物已经知道的事情；
- 结尾用反转、动作回扣、评论问题或下一条承诺收束。

## 连续性与防复刻

系列剧情维护人物身份、称谓、关系站队、固定场景、口头习惯、已发生事件、产品状态和未兑现钩子。

成稿后把正文保存到临时文本并运行：

```bash
python scripts/local_search.py similarity-check path/to/draft.txt
```

若 `max_similarity >= 0.18`，重写最相近的事件链、对白或道具组合；出现连续12字以上明显相同表达也必须改写。不得向用户披露源文件全文。

## 输出与回执

默认输出项目定位、人物、时长、场景、分段脚本、字幕/音效、植入说明和结尾钩子。用户给定模板时优先遵循模板。

最终附：`本地达人脚本库：检索N次，共参考N份脚本；仅采用机制与节奏，已完成防复刻检查；运行时未联网。`
