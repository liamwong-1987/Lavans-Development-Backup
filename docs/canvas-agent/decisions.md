# Canvas AGENT 已确认决定

最后更新：2026-08-20

1. 不做一键直接成片；一句话只启动工作流。
2. 关键阶段必须人工审核，阶段内部低风险步骤可自动执行。
3. 审核使用“画布审核节点 + 右侧专业审核栏”。
4. 上游变化后保留下游全部成果，精确标记 `needs-review / stale`，由用户决定重做范围。
5. 采用独立版本依赖与审核引擎。
6. 交付路线使用 10 个阶段。
7. 画布 AGENT 与一键复色是完全独立的软件，不共享素材、模板、任务、设置、Provider 或模型选择。
8. 开发只使用 GPT/Codex；运行时读取画布 API 设置中用户配置的语言、图片和视频模型。
9. 能勾选的问题不得要求用户打字；仅“其他”展开文字输入。
10. 所有付费调用必须展示并精确绑定 Provider、模型、输入版本、数量、预算、重试上限和操作 ID。
11. 阶段 4 拆为结构化分镜、资产锚点台账和覆盖校验三个独立审核节点；前一节点锁定后才允许产生后一节点。
12. 上传资料在用户界面只显示真实文件名，不展示内部资料编号；不存在的资料引用必须由后端阻断。
13. 阶段 5 的站点和模型分开保存；设置只读取画布 API 配置，不读取一键复色配置。
14. 自动模式只允许在当前已批准批次内连续执行，永远不能越过剧本、分镜、旁白、资产、逐镜视频或最终合成人工审核关。
15. 阶段 5 三个策略节点同时展示，用户只需在最终安全门节点提交一次审核，后台统一批准并锁定三项策略。
16. 阶段 6 先建立精确付费批次，再逐项生成角色、产品、场景、道具与 Logo；产品必须携带实拍图，文档只用于事实约束，不能作为图片参考上传。
17. 阶段 6 每项资产用卡片单选一个版本，用户最后只提交一次；测试替身必须在图片和文字中明确标注，不能与真实模型结果混淆。
18. 阶段 7 每个镜头分别选择首帧和尾帧，故事板和调度图与选择结果一起只提交一次；锁定后停止，不自动进入声音、逐镜视频或最终成片。
19. 调度图使用本地确定性规则生成，不调用付费模型；正式首尾帧仍复用画布图片 API，并精确绑定阶段六锁定资产版本。
20. 阶段 8 锁定声音、字幕和逐镜制作包后停止；阶段 9 每镜头独立生成和验收，任何失败只影响当前镜头。
21. 阶段 10 正式合成只接受锁定、当前有效且时长一致的阶段八与阶段九输入；缺一个镜头也不能生成最终品牌成片。
22. 阶段 10 使用本地 FFmpeg 合成和自动质检；最终人工清单全部勾选后只提交一次，统一锁定 MP4、SRT、质检报告、版本来源说明和 ZIP。受控测试素材必须隔离并显著标记，不能作为正式品牌交付。
