# AGENT / API 模型分类修复：阶段 4 断点

## 目标

在现有 API 设置界面内显示并保存图片、LLM、视频、音频、未知五类模型；最新上游分类可以纠正历史自动误分，用户明确人工分类始终优先。

## 设计与边界

- 模式：Extension，沿用现有页面布局、主题、弹窗和交互密度。
- 分类优先级：人工分类 > 最新上游分类 > 后端能力建议 > 历史列表 > 未知。
- 无法判断的模型进入“未知”，不得再默认放入 LLM。
- 人工分类保存为独立覆盖表，不修改模型真实 ID，不用展示名称替代请求 ID。
- 本阶段不真实调用 Provider、不生成媒体、不改变 API Key、不改 AGENT 对话或一键复色。

## 任务卡

- 推荐模型：Terra；最终复核按 Sol 标准执行。
- 当前执行者：当前主智能体；未授权子智能体。
- 推理强度：high。
- 允许修改：API 设置模型分类界面、分类覆盖持久化、对应本地测试和本断点文档。
- 禁止修改：真实请求协议、Provider 自动切换、阶段 3 精确 ID、画布节点、复色功能、依赖和 Git 历史。
- 验收：五类可见；音频/未知不丢失；人工分类重启保留；官方分类能修复无人工覆盖的历史误分；未知不进入 LLM。
