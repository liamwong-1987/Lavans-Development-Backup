# Lavans 一键复色系统优化总方案

> 本文档是一键复色系统 UI 与代码改造的唯一任务总纲。任何窗口切换或上下文压缩后，继续工作前必须先读取本文档。本文档不代表已开始修改产品代码。

> 一键复色最终页面结构、状态、交互与验收细节统一执行 `docs/ui-design-system-v1/LANVAS_RECOLOR_FINAL_DESIGN_SPEC_V1.md`；本文件保留任务背景、决定来源和改造总纲。

## 1. 当前决策

- 当前仅完成需求整理与 UI 方案探索。
- 在用户确认最终浅色、深色 UI 效果图之前，不修改产品功能代码。
- UI 确认后，开始改造整个 Lavans 软件 UI，而不是只美化一键复色页面。
- 改造必须保护现有功能以及用户后续增加的功能。
- 本轮以重新设计 UI 为主，同时允许实施用户已经明确确认的一键复色功能修复与新增能力（任务真实性、按需导出、可选裁剪、本地 HEX 管理等）。未被明确确认的功能、名称、描述文案、导航顺序和其他业务逻辑继续冻结。
- 2026-08-22 用户确认浅色主页面、提示词主体和历史结果三张效果图；同时确认单次调用价格可在提示词窗口左下角按元/次手动修改或恢复系统默认，并联动顶部费用、开始生成确认、重做确认和独立任务执行汇总。
- 2026-08-22 用户确认批次锁价：首次开始生成时锁定本批次单价；运行中改价只影响下一批，不倒算已经发生的调用费用。任务执行汇总同时显示当前批次锁定价与下一批价格，所有位置读取同一价格设置。
- 2026-08-22 用户确认按需导出、参考色可选批量裁剪和免费本地取色：导出默认全部，也可按上传批次、参考色、模板图和仅未导出组合筛选；每个结果版本保留“已导出”标记。参考色同批次可只裁一次并批量应用，异常比例单独提示。
- 2026-08-22 用户最终澄清 HEX 边界：本机吸出的色号只用于色块、筛选、分组、历史和导出命名，不写入提示词、不发送给 API、不参与模型生成或质量判断。取色错误不影响生成图，生成前后都可免费修正元数据；只有更换实际参考图并主动重做才会改变生成结果。
- 2026-08-22 用户统一确认全规则审计的 9 项推荐修正：原模型下架需确认改绑未提交任务；未知网络结果禁止自动重发；任务采用主状态加运行标记；混合模型确认逐项显示；密钥提交时读取全局最新配置；执行批次原子结束；图片保存成功后才算已生成；HEX 改名触发名称待重新导出；组合筛选采用同类 OR、跨类 AND 并冻结导出版本。
- 2026-08-21 用户再次确认：画布与一键复色共用同一个 API 设置。画布 API 设置完成后，一键复色直接读取同一套 Provider、模型列表、密钥和调用能力；一键复色不建立独立 API 设置或第二份密钥。
- 2026-08-21 用户最终确认免确认规则：`等待生成 → 生成中 → 已生成 / 生成失败 / 已删除`。API 每次只生成一次就停止；不设置“确认通过”，系统不得代替用户判断色差，也不得自动重做。
- 2026-08-21 用户明确否决圈选/Mask：正式产品只采用整张图片自然复色，不提供圈选，也不把圈选作为备用方案；禁止把圈内生成结果与圈外原图硬拼接。系统通过整图对比检查背景、文字、结构、光影和纹理是否被误改。
- 2026-08-21 用户确认色差处理原则：色差完全由用户查看对比图后判断。用户点击一次“重做”，系统使用该任务创建时绑定的模型，把整张模板图和该任务实际参考图提交一次；生成后立即停止。本地不调色、修图或拼接。每项任务最终只保留一张最新成功结果。
- 2026-08-21 用户确认任务行操作：只保留“重做”和“删除”两个操作按钮，不提供逐任务“确认通过”。删除在等待、生成中和已生成阶段都可立即执行；点击后立即从界面隐藏并进入 5 秒待删除期，超时后才从本地队列移除并尽力取消远端调用。若服务商不支持取消，必须提示本次调用可能仍产生费用，迟到结果不得让已删除任务重新出现。
- 2026-08-21 用户确认删除保护：点击删除后任务立即从列表隐藏，底部提供 5 秒“撤销”；5 秒内撤销恢复原任务，超时后才正式删除本地任务与结果，并尝试取消仍在生成的远端任务。删除过程不弹确认框。
- 2026-08-21 用户确认重做费用保护：点击“重做”不得直接调用 API，必须先弹出确认框，明确提示将产生 1 次新的 API 调用；只有点击“确认重做”才执行，默认安全操作为“取消”。
- 2026-08-21 用户明确要求：重做确认弹窗本身也必须纳入本轮 UI 重新设计，不得沿用浏览器默认确认框、旧弹窗换色或临时样式补丁。
- 2026-08-21 历史决定，已被后续决定覆盖：首次批量生成曾计划不显示确认弹窗；现行规则以正式生成确认弹窗为准。
- 2026-08-21 用户确认系统错误熔断：一旦发现密钥失效、余额不足、模型不可用或接口地址错误等全局 API 问题，必须立即暂停整个批次，不等待连续失败；普通单张内容或生成错误只标记该任务失败，其余任务继续。
- 2026-08-21 用户确认暂停恢复方式：全局 API 问题修复后，系统检测恢复正常应优先自动继续生成；界面同时保留“继续生成”按钮供用户手动恢复。自动和手动恢复都必须先做不生成图片、不产生图片生成费用的可用性检查，通过后才恢复队列。
- 2026-08-21 用户确认运行中追加：生成过程中新增图片形成的新任务必须自动加入当前队列并继续生成，不需要再次点击“开始生成”；允许用户主动创建相同素材组合，后台只按唯一任务编号防止同一任务被重复领取和重复调用，并立即更新任务统计。若批次处于暂停状态，新任务只入队，恢复后再执行。
- 2026-08-21 用户确认配对与展示顺序：采用“模板图 1 × 全部 N 个参考色 → 模板图 2 × 全部 N 个参考色 → 模板图 3 × 全部 N 个参考色”的模板优先全组合方式；不是一对一配对，也不得按颜色把不同模板交叉混排。
- 2026-08-21 用户确认运行中新增参考色的列表位置：由新增参考色产生的任务统一追加到当前连续列表末尾，不插回各模板原位置，也不移动已有行；新增部分内部按模板图顺序排列。
- 2026-08-21 用户确认顶部统计：删除“成功率”，固定显示“任务总数、已生成、生成中、失败”。“已生成”仅表示 API 返回图片；删除超过 5 秒撤销期并正式落定后，不再计入任务总数。
- 2026-08-21 用户确认右栏行为：点击任务后右栏锁定该任务；没有手动选择时显示最新生成结果。右侧对比区只显示模板图和生成图两张，不显示参考色图、自动质检或色差判断。
- 2026-08-21 用户确认底部固定操作栏只有“开始生成、导出结果、彻底清空”三个按钮。“彻底清空”取代原“重置”，清除一键复色内部全部数据：上传素材、任务、配对记录、生成结果、缓存、临时文件和日志；不得触碰画布数据、全局 API 设置或全局主题。
- 2026-08-21 用户确认彻底清空的运行中规则：必须先弹出重新设计的危险确认框；确认后停止本地队列、尝试取消远端任务，再清除全部一键复色数据。操作不可撤销，远端无法取消时提示可能仍产生费用，迟到结果直接丢弃。
- 2026-08-21 历史决定，已被 2026-08-22 按需导出规则部分覆盖：导出默认仍为全部最新结果，但用户可在正式弹窗中主动按上传批次、参考色、模板图和仅未导出筛选；主任务筛选不影响导出。右栏继续使用可拖动双图对比线。
- 2026-08-21 用户确认上传与任务创建：顶部保留模板图、参考色两个大面积拖拽框，二者占满上传区且点击/拖拽命中范围足够大；普通添加后自动配对并创建任务，裁剪后添加在用户确认预览后创建任务，不再要求点击扫描配对。
- 2026-08-21 用户确认任务行与右栏：任务行取消复选框，只显示编号、模板图到生成图、状态/进度、重做、删除；右栏上半部为双图对比，下半部为日志，可折叠且展开后保持锁定任务。
- 2026-08-21 用户确认彻底清空弹窗也要正式重做 UI：采用紫域工作台深浅色同构设计，显示不可撤销范围与运行中费用风险，默认焦点为取消，不要求输入文字。
- 2026-08-21 用户授权导出命名方案：不使用 `01-xx` 纯序号。单模板压缩包为 `YYYYMMDD-模板名-复色结果.zip`；多模板为 `YYYYMMDD-首个模板名等N张-复色结果.zip`；包内图片为 `模板名-参考色名-YYYYMMDD-HHmmss.png`，仅发生同名冲突时追加 4 位短识别码。
- 2026-08-21 用户确认底部主按钮状态：同一位置按队列状态显示“开始生成”“暂停生成”“继续生成”，不得同时摆放三个按钮。
- 2026-08-21 用户确认运行中导出：生成过程中允许导出，ZIP 只包含导出当时已经生成完成的全部最新结果，未完成任务继续运行。
- 2026-08-21 用户确认上传区已选状态：显示第一张缩略图和文件总数，并提供“继续添加”“移除全部”；拖拽框继续保持较大占比和命中面积。
- 2026-08-21 用户明确允许业务重复：完全相同的模板图或参考色可以重复上传，相同模板与相同参考色可以主动创建多次生成任务，不得提示“已存在”并阻止。每次主动创建使用独立任务编号；后台仍须按任务编号保证幂等，防止刷新、恢复或重复领取造成同一任务重复扣费。
- 2026-08-21 用户确认彻底清空后可重新创建相同组合，但彻底清空不是允许重复生成的唯一前提。
- 2026-08-21 用户确认日志与筛选：右侧日志默认显示最近记录，错误红色标记并置顶，保留清空日志；任务列表提供全部、已生成、生成中、失败四个快捷筛选，连续滚动、不分页。
- 2026-08-21 本轮头脑风暴最终收口：首次点击“开始生成”改为使用正式设计的生成确认弹窗，显示任务数、当前模型、并发数和预计调用次数；这一决定覆盖此前“首次批量生成不弹确认框”的旧记录。无任务时开始生成置灰，无已生成结果时导出置灰。
- 2026-08-21 并发规则：允许设置 3–8，首次默认 8，记住上次设置。入口放在开始生成按钮旁的并发设置图标中；调整后立即生效但不打断已运行任务，降低时自然回落，提高时立即补足空位。
- 2026-08-21 任务模型采用创建时快照：已进入队列的任务继续使用创建时模型；用户在全局 API 设置中切换模型后，只影响此后新建任务。任务列表不增加模型列，状态悬停与右侧详情显示实际模型。
- 2026-08-21 普通单任务失败不自动重试，原位显示简短中文原因并继续后续任务；完整错误放入悬停提示和日志。生成中不显示虚假百分比或确定性进度条，只显示状态旋转图标与从左向右循环的细紫色流光。
- 2026-08-21 列表仍为一个连续列表，但每个模板组第一条上方增加轻量、滚动时短暂吸顶的“模板名 · N 种颜色”分组标题；这一决定覆盖此前“不增加分组标题”的旧记录。任务位置在并发返回、失败、重做和追加期间保持不变。
- 2026-08-21 任务行维持模板图与生成图两张中等偏大缩略图，一屏约 5–6 行；任务名称旁增加参考色色块，不增加第三张参考图缩略图。上传区可收起，任务表头和底部操作栏固定，仅列表滚动。
- 2026-08-21 右栏仍为模板图/生成图双图对比；点击右栏预览或列表中的模板图、生成图后，进入全屏三图对比，顺序固定为模板图、生成图、颜色图。颜色图显示模型实际收到的参考图；裁剪场景可另行查看上传原图。三图支持鼠标缩放和左右方向键切换任务，底部提供紫色“重做”按钮。
- 2026-08-21 全屏提交重做后保持打开，旧图覆盖“正在重做”流光并继续显示；用户可立即切换和重做其他任务。新图成功原位替换，失败保留旧图和失败原因。
- 2026-08-21 单张重做采用非阻塞队列：每次费用确认后立即生成或按实际进入时间加入统一 FIFO 队列，不插队；多张重做按点击顺序入队，同一任务在重做等待/运行期间禁止再次重做，其他任务的重做按钮始终可用。重做与普通任务共享并发上限；暂停时只入队不执行；正在重做的任务仍可删除。
- 2026-08-21 暂停只停止领取新任务，已提交 API 的任务继续完成。系统性错误使用列表顶部红色提示条，不使用阻断弹窗；非付费健康检查连续两次成功后自动继续，并保留立即检测和手动继续。
- 2026-08-21 关闭软件时如有运行任务，提供“缩小到后台继续生成”和“暂停并退出”；意外关闭或重启后恢复原列表，未提交任务保持等待，状态未知任务先查询，防止重复扣费。
- 2026-08-21 删除已完成任务在 5 秒撤销期后清除任务记录、生成图和相关缓存，但保留原始上传素材。“移除全部”只移除上传素材及其尚未开始的关联任务，不影响运行中或已生成任务。
- 2026-08-21 完成提醒显示“本批次已完成：生成 N 张，失败 N 张”，后台时使用系统通知且不播放声音。右侧日志默认精简显示最近记录，可展开全部，红色系统错误置顶。右栏支持拖动改宽、折叠并记住宽度。
- 2026-08-21 全部任务结束后主按钮显示“生成完成”并置灰；新增素材形成新任务后恢复“开始生成”。运行中导出完成提示“已导出当前完成的 N 张图片，剩余任务仍在生成。”重复任务在可读名称后使用创建时间和 4 位短识别码区分。
- 2026-08-21 用户进一步澄清全软件推广边界：只有一键复色的 UI 视觉设计作为全软件样板，包括配色、文字、字体、图标、按钮、弹窗、状态表达、组件质感和深浅色规则。一键复色的上传配对、批量生成、并发、任务队列、重做、导出等功能不是全软件功能样板；三栏版面、任务表格和业务交互也不得机械复制到其他页面。

## 2. 品牌和系统边界

- 软件统一品牌为 `Lavans`，产品界面不再出现 `Lavans`。
- 一键复色和无限画布是同一大软件中的两套独立软件。
- 素材、项目、任务、队列、结果、模板、生成记录完全隔离，双方不可互访。
- 仅共享全局深浅色状态和软件唯一 API 体系，包括站点、模型、账号密钥及调用能力。
- 一键复色内部不设置独立 API 按钮；只删除一键复色内部自己的深浅色切换按钮，软件全局主题继续保留。
- 一键复色原“重置”入口由底部“彻底清空”取代，不再保留重复的顶部重置按钮。

## 3. 保留的布局骨架

- 保留 INDEX 外层全软件左侧栏。其功能、名称、描述和顺序全部原样保留，只允许视觉样式重设计。
- 红框内区域才是一键复色系统；最左侧全软件导航不属于一键复色内部。
- 全局导航现有名称固定为：本地功能、文生图、细节增强、图片编辑、角度控制、在线生图、GPT 对话、无限画布、素材库、一键复色、API 设置、更多设置、深浅模式、语言、工作流设置、项目主页。名称和顺序不得擅自改动。
- 保留一键复色内部左、中、右结构：内层图标栏、中央任务区、可折叠右栏。
- 中央任务列表占可用工作区约 70% 至 80%，是绝对主工作区。
- 右栏承载模板图/生成图双图预览与日志，并支持折叠；不放参考色图、自动质检或色差判断。
- 不以重新设计为理由删除未被后续确认覆盖的真实功能；已经确认合并的重复空壳页面、扫描配对、旧重置和旧窄栏入口按最终规格迁移。
- 一键复色内层窄栏现行固定为 8 个真实快捷入口：提示词设置、历史结果、上传区展开/收起、聚焦任务搜索、只看生成中、只看失败、打开最新生成结果、右侧检查栏开关。旧“上传素材、智能配对、批量生成、结果输出、日志中心”独立空壳入口已被合并规则覆盖。

## 4. 功能优化清单

### 4.1 素材与配对

- 模板图和参考图上传。
- 模板图与参考色各使用一个大面积拖拽框，两框平分上传区主宽度，整张卡片均可点击和接收拖拽；上传后可以压缩高度，但不得退化为窄小按钮或难以命中的区域。
- 上传后显示第一张缩略图和当前文件总数，并提供“继续添加”“移除全部”；已选状态仍保留足够大的拖拽命中区。
- 复色任务上传只接受 JPG、PNG、WEBP 图片。文档、Markdown 和压缩包不进入复色上传、配对、裁剪、取色或 API 生成流程。
- 普通上传完成后自动配对并创建任务；裁剪后添加必须先确认批量预览。两条路径都不设置额外“扫描配对”步骤；任务搜索、排序和筛选继续保留。
- 每张模板图必须与当前全部参考色生成组合任务，任务数量为模板图数量 × 参考色数量。
- 所有任务进入同一个连续列表，并保留已经确认的轻量模板分组标题；不增加折叠区或独立列表容器。
- 连续列表只按模板优先顺序排列：模板图 1 的颜色 1 至 N，接着模板图 2 的颜色 1 至 N，再到后续模板。
- 新增模板图时，把“该模板 × 全部现有参考色”的任务追加到同一列表；新增参考色时，为每个现有模板补充该颜色任务。用户重复上传同一素材时也允许创建新的独立任务，不按素材内容阻止重复组合。
- 运行中新增参考色产生的补充任务一律追加到列表末尾；追加块内部按模板图 1、模板图 2、模板图 3 的顺序排列。现有任务行不得重新排序或跳动。
- 即使并发生成导致返回先后不同，连续列表中的既定任务位置也必须稳定，不得跳动或混排。

### 4.2 生成设置与主流程

- 从软件统一 API 体系读取站点和模型。
- 画布 API 设置完成后，一键复色必须无需重复配置即可使用；复色页面只读取和选择统一 API 体系提供的能力，不保存独立 Provider、模型列表或密钥。
- 支持尺寸、质量、数量、生成成本预估。
- 每个区域最多一个主按钮，生成入口统一为“检查或确认设置并生成”。
- 底部生成主按钮占用同一固定位置，并随队列状态切换文字与行为：空闲为“开始生成”，运行中为“暂停生成”，暂停后为“继续生成”。
- 支持暂停、继续、取消、失败重试、局部重做、批量下载和结果打包。
- 任务队列是运行期间可追加的唯一实时队列。新增图片完成扫描与配对后，新任务必须以唯一任务编号原子加入当前队列，并由执行器确认领取；不得只写入磁盘却漏执行。
- 用户主动创建的相同素材组合必须允许，每次分配独立任务编号。执行器只按任务编号做幂等保护，防止刷新、恢复或重复领取让同一个任务调用两次；不得用素材指纹阻止用户有意重复生成。任务总数、等待数、生成中和已生成统计随追加即时更新。
- 顶部统计固定为四项：任务总数、已生成、生成中、失败。不得显示会被误解为复色质量判断的“成功率”。
- 任务总数只统计当前有效任务；待删除的 5 秒内保留原统计，删除正式落定后从总数及对应状态统计中移除。
- 队列运行中追加后直接继续执行，不再次弹确认框或要求点击开始生成；队列暂停时允许追加但不得抢跑，恢复后按队列执行。

### 4.3 任务列表

- 取消分页，使用连续滚动或按需加载。
- 保留并放大缩略图，让用户能直接发现复色问题。
- 任务列表每行只显示两张缩略图：模板图、生成图。参考色继续用于上传、配对和 API 生成，但不进入任务行或右侧预览。
- 每个任务的操作栏只放图标形式的独立重做和删除按钮；预览通过点击缩略图进入右栏，下载统一放在批量/导出区域，避免任务行按钮拥挤。
- 任务行不显示复选框，只显示编号、模板图到生成图、状态/进度、重做和删除。
- 任务列表提供全部、已生成、生成中、失败四个快捷筛选，使用连续滚动，不使用分页。
- 点击任一任务行后，右栏锁定显示该任务；其他任务生成完成不得抢走当前选择。尚未手动选择时，右栏显示最新生成结果。
- 底部固定操作栏只能出现开始生成、导出结果、彻底清空三个按钮，并在各种窗口高度下完整可见。
- 导出结果始终包含全部任务的最新生成结果，不受全部、已生成、生成中、失败筛选影响。
- 生成过程中允许导出；导出包只收集点击导出时已经生成完成的全部最新结果，其余任务继续运行。完成后提示实际导出张数。
- 失败状态和具体原因位于同一任务行，不另起一行。
- 清楚显示任务状态、进度、成本、耗时和 API 调用次数，不显示自动质检结论。

### 4.4 双图预览

- 右侧预览只显示模板图和生成图两张，采用同一画框中的可拖动对比线；点击可放大查看。
- 右栏上半部固定为双图对比，下半部为系统日志；折叠后再次展开必须保留原锁定任务和对比位置。
- 支持键盘左右键切换上一项和下一项任务。
- 右侧预览不显示参考色图、自动质量结论或色差数值，色差由用户自行查看双图判断。
- 失败原因必须对普通用户可读，不显示内部 JSON。
- 任务状态固定为：等待生成、生成中、已生成、生成失败、已删除。
- “已生成”只表示 API 已正常返回图片，不代表系统判断颜色正确；界面不要求用户逐张确认。
- 系统不得自动判断色差、自动判定质量或自动触发重做。右栏只展示模板图和生成图供用户比较。
- 正式流程不提供产品区域圈选或 Mask 上传。生成必须采用整图自然复色，检测必须对比生成前后整图中的背景、文字、结构、光影和纹理；禁止硬边裁切和拼接。
- 用户认为存在色差并点击一次“重做”后，调用当前 API 模型一次；生成完成后立即停止并进入“已生成”。重做期间旧结果仅作临时保护：新图生成成功后替换并删除旧图，重做失败则保留旧图，确保任务始终只有一张最新成功结果。不得连续自动重做，也不得使用本地算法直接改色。
- 重做确认框至少显示当前任务缩略图、当前模型和“本次将产生 1 次新的 API 调用”；按钮为“取消”和“确认重做”。默认焦点必须位于“取消”，关闭弹窗或按 Esc 不产生调用。
- 重做确认框采用“紫域工作台”统一组件：标题“确认重新生成”、当前图片缩略图、模型信息、费用提示和旧图替换说明形成清晰信息层级；底部左侧为次级“取消”，右侧为唯一深紫主按钮“确认重做”。浅色与深色结构、尺寸和位置完全相同，仅材质与颜色变化。
- 首次批量生成使用独立的正式确认弹窗，显示任务数、当前模型、并发数和预计调用次数；它与单张重做费用确认弹窗是两套不同内容的统一 UI 组件。
- 删除按钮在等待生成、生成中、已生成和生成失败状态下均可使用。点击后先标记为待删除并立即从可见列表隐藏；5 秒超时后再从执行队列移除并尝试取消远端任务。远端无法取消时丢弃迟到结果，已删除任务不得复活。
- 删除采用“立即隐藏、延迟 5 秒落定”：任务先进入待删除状态并显示可撤销提示，期间不永久删除文件；超时后执行正式删除与远端取消。若用户撤销，任务及已有结果按删除前状态恢复。

### 4.5 日志与异常恢复

- 日志支持全部、信息、成功、警告、错误筛选。
- 日志提供刷新与清空，避免无限累积。
- 右栏默认只展开最近日志；错误记录使用红色状态标记并置顶，保留“清空日志”。
- “彻底清空”与“清空日志”不是同一操作：前者清除一键复色内部全部数据，后者只清日志。
- “彻底清空”属于不可撤销的危险操作，必须使用重新设计的确认弹窗，明确列出上传素材、任务、配对记录、生成结果、缓存、临时文件和日志都会删除；不得使用浏览器默认确认框，也不得触碰画布数据、全局 API 设置或全局主题。
- 彻底清空弹窗按紫域工作台重新设计：标题“彻底清空一键复色数据”，使用真实警告图标与危险色语义，正文分层列出删除范围和不可撤销说明；按钮为取消、确认彻底清空，默认焦点位于取消，不要求输入确认文字。浅色与深色结构、尺寸和位置完全一致。
- 运行中确认彻底清空后，先停止本地队列并尝试取消远端任务，再清理本地数据；远端无法取消时提示可能仍产生费用，迟到结果直接丢弃且不得恢复任务。
- 导出生成 ZIP。默认全部，也可按已确认条件筛选；ZIP 与包内图片使用最终规格第 22 节的日期、上传批次、模板名和 `HEX-RRGGBB` 语义命名规则。
- ZIP 内图片不使用 `01-xx` 等纯序号，命名为 `模板名-参考色名-YYYYMMDD-HHmmss.扩展名`；仅在仍发生同名冲突时追加 4 位短识别码。保留中文可读名称，并自动替换文件系统禁用字符。
- 当用户主动生成相同模板与相同参考色且时间仍重名时，使用 4 位短识别码区分文件；不得回退为 01、02 等纯序号。
- API失败、违规、超时、中转站异常只影响对应任务。
- 人工重做只作用于用户选中的任务，不重复生成其他任务；重做继续使用该任务所属执行批次锁定的提示词和单价。运行中修改提示词只影响下一执行批次，不倒改既有任务。
- 全局 API 错误采用一次触发立即熔断：密钥失效、余额不足、模型不可用、接口地址错误或同等级配置问题一经确认，立即停止领取新任务并暂停整个批次。
- 单任务素材、内容安全或偶发生成错误不得暂停整批，只让当前任务进入生成失败并继续后续任务。
- 暂停提示必须使用普通中文说明暂停原因和需要处理的位置，不向用户倾倒原始 JSON。
- 熔断暂停后，系统监听全局 API 设置变化并进行非生成型可用性检查；确认恢复后自动继续领取未完成任务。
- 暂停状态必须保留“继续生成”按钮。用户点击后立即执行同一套非生成型检查，通过则继续，不通过则保持暂停并显示可读原因。
- 不得为了判断是否恢复而偷偷提交付费图片生成任务；服务商没有免费检查能力时，只能在全局设置更新或用户点击继续后校验，不得伪装成已恢复。
- 危险操作放入二级菜单并二次确认。
