# 一键复色三图并排灯箱 + 左右切换 — 改动报告

**日期**：2026-08-18
**模块**：一键复色任务列表图片预览
**性质**：功能增强（单图灯箱 → 三图并排 + 任务间切换）

---

## 一、改动目标

点击任务列表任意缩略图，灯箱同时展示该任务的模板图、参考图、生成图三张并排，并可通过左右箭头或键盘 ← → 键切换到上一个/下一个任务。

## 二、改动清单（只改 `app.js`）

| 改动 | 说明 |
|------|------|
| `initImageViewer()` 灯箱 HTML | 新增 `#rv-container`（三图 flex 横排 + ← → 箭头按钮），保留原有 `#img-viewer-image`（供详情页/上传预览单图使用） |
| 键盘监听 | 扩展为 ESC 关闭 + ← → 切换 |
| `openImagePreview()` | 增加单图/行预览模式切换（显示 `#img-viewer-image`，隐藏 `#rv-container`） |
| 新增 `openImageRowPreview(el)` | 从点击的缩略图找到父级 `.task-row`，收集所有可见任务行，读取三张缩略图填充灯箱 |
| 新增 `loadRowPreview(index)` | 按索引加载三张图 + 更新标题 + 控制箭头显隐 |
| 新增 `navigateRowPreview(step)` | 索引 +1/-1 切换，调用 `loadRowPreview` |
| `closeImagePreview()` | 补充清空三张图 src + 重置索引 |
| 三张缩略图 onclick | `openImagePreview(...)` → `openImageRowPreview(this)` |

## 三、交互说明

| 操作 | 行为 |
|------|------|
| 点击任务行任意缩略图 | 打开三图并排灯箱 |
| 点击 → 箭头 / 按键盘 → | 切换到下一个任务的三张图 |
| 点击 ← 箭头 / 按键盘 ← | 切换到上一个任务的三张图 |
| 第一条任务时 ← 隐藏 | 已达边界 |
| 最后一条任务时 → 隐藏 | 已达边界 |
| 按 ESC | 关闭灯箱 |
| 点击背景遮罩 | 关闭灯箱 |

## 四、兼容性

- 详情页、上传预览等仍使用 `openImagePreview()` 的单图模式，不受影响。
- 任务行即使某张图缺失，该槽位显示为空白占位，不影响整体布局。

## 五、验证

- `node --check app.js` 语法通过。
