# Canvas AGENT 开发任务总表

最后更新：2026-08-20

## 永久约束

1. 画布 AGENT 与一键复色是两套完全独立的软件，不共享素材、模板、任务、设置或 API 选择。
2. Lavans 的代码开发与修复只使用 GPT/Codex；画布 AGENT 的运行模型不得写死，必须读取画布 API 设置中当前选定且已配置的 Provider 与模型。
3. 保留现有画布和用户后来增加的功能；每阶段修改前创建精确备份。
4. AGENT 每一步必须先在画布创建可见节点，再开始真实执行。
5. 节点必须展示等待、运行、待确认、完成、阻塞、失败、暂停和取消状态。
6. 用户可以中断；取消不得删除已经完成的节点和产物；失败只重试失败阶段或镜头。
7. 图片和视频付费调用必须遵守手动、半自动、自动模式以及预算、数量、重试上限。
8. 缺少真实依赖时必须阻塞，禁止生成伪造回执或伪造产物。
9. 每完成一个阶段立即停止，等待用户验收通过后再进入下一阶段。
10. AGENT 问询必须“选项优先”：能枚举答案的问题使用单选或多选，默认不显示文字框；只有选择“其他”时才展开补充输入。放大字体时选项卡必须同步增高并允许说明文字正常换行。

## 已完成基础

- 多 Skill 卡片入口、动态 Skill 注册和对话式问卷。
- 图片、文档、MD、压缩包等 AGENT 资料上传。
- Run、Stage、Artifact 持久化和刷新恢复。
- 产品事实与项目初始化真实执行。
- 阶段节点、状态灯、暂停、继续、取消基础能力。
- 故事依赖缺失时安全阻塞，以及授权故事数据库上传和离线校验入口。

## 新版 10 阶段交付路线

| 阶段 | 任务 | 核心验收结果 |
|---:|---|---|
| 1 | 执行底座与恢复账本 | 统一版本依赖、审核、影响传播、费用安全门和新窗口恢复全部通过 |
| 2 | 产品事实与调研 | 用户确认资料事实、证据等级、禁说项、故事检索和创意研究边界 |
| 3 | 创意与剧本锁定 | 创意、完整剧本、局部修改、版本比较和唯一锁定版本通过审核 |
| 4 | 结构化分镜与资产台账 | 逐镜脚本与角色、产品、场景、道具、Logo 引用关系完整并锁定 |
| 5 | 模型策略与费用防线 | Provider、模型能力、比例、模式、预算、备用与重试获得精确批准 |
| 6 | 视觉资产生产 | 角色锚点、产品保真、场景、道具均有版本并由用户锁定 |
| 7 | 分镜图、故事板与调度 | 逐镜画面、首尾帧、故事板、机位、站位和运动路线全部锁定 |
| 8 | 声音与逐镜制作包 | 旁白、对白、字幕、音乐、音效和逐镜视频提示词全部锁定 |
| 9 | 逐镜视频生产与验收 | 每个镜头独立生成、独立验收；失败只重试该镜头，批量付费前确认 |

## 模型与设置界面原则

- 输入框保留资料、快速模型、项目资料、执行模式、完整设置和执行入口。
- 快速模型选择器负责本次任务；完整设置负责默认 API、模型、比例、数量、时长、预算和备用策略。
- API 站点与模型分开选择；模型卡显示能力、比例、时长、价格、速度和可用状态。
- 设置优先级：单节点 > 当前项目 > 当前 Skill > 画布 AGENT 全局默认。
- 自动模式必须受预算、数量、重试和高价模型确认限制。
