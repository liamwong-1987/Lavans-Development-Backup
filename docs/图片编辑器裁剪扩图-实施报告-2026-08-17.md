# 图片编辑器（裁剪 + 扩图）实施报告

- **日期**：2026-08-17
- **模块**：复色画布（canvasStudio.js）
- **类型**：画布复刻——图片编辑器第一阶段

## 结论

复色画布图片编辑器的**裁剪（crop）**和**扩图（outpaint）**两个模式已完整实现，代码落地、语法通过、函数闭环。属画布复刻「图片编辑器」三大缺口之一，本次交付前两个核心模式，遮罩/画笔/宫格/缩放留待后续阶段。

## 实现内容

### 1. 编辑器弹窗 HTML（canvasStudio.js 主字符串内）

`#canvas-image-edit-modal`，结构：

| 区块 | 内容 |
|------|------|
| 头部 | 标题「编辑图片」+ 关闭按钮 |
| 模式切换 | 裁剪 / 扩展 两个按钮 |
| 裁剪工具栏 | 比例：自由 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16 |
| 扩图提示 | 「拖动裁剪框向外扩展，白色区域将被填充」 |
| 舞台 | `#canvas-crop-canvas` > `#canvas-crop-image` + `#canvas-crop-box`（4 个角手柄） |
| 底部 | 「应用裁剪」按钮（扩图模式变「应用扩展」） |

### 2. JS 函数组（14 个）

- 状态变量：`cropState` / `cropDrag` / `cropAspectPreset` / `cropAspectRatio` / `imageEditMode`
- `openCanvasImageEditor(nodeId, mode)` — 打开编辑器，加载图片，绑定事件
- `closeCanvasImageEditor()` — 关闭、清理状态
- `setCanvasImageEditMode(mode)` — 切换裁剪/扩展，显示对应工具栏
- `syncCanvasCropRatioButtons()` / `setCanvasCropRatio(preset)` — 比例切换
- `canvasCropBounds()` / `resetCanvasCropBox()` / `renderCanvasCropBox()` — 裁剪框计算与渲染
- `clampCanvasCrop()` / `clampCanvasOutpaint()` — 边界约束
- `bindCanvasImageEditor()` — 裁剪框拖拽（移动 + 四角缩放），pointer 事件
- `uploadCanvasCroppedBlob(blob, name)` — 上传到 `/api/canvas/local-assets/upload`
- `applyCanvasImageCrop()` — canvas 裁剪 → 上传 → 更新节点 → 渲染 → 保存
- `applyCanvasImageOutpaint()` — 白底 + 原图扩图 → 上传 → 更新 → 渲染 → 保存

### 3. 图片节点入口

图片节点 body 的悬浮菜单里，`canvasMediaKind(item) === 'image'` 时显示「✎ 编辑图片」按钮，点击打开编辑器。

### 4. CSS（style.css）

完整样式 + dark theme 覆盖：`.image-edit-panel` / `.image-edit-mode` / `.image-edit-tools` / `.image-edit-stage` / `.crop-canvas` / `.crop-box` / `.crop-handle` / `.image-edit-actions` / `.image-edit-btn`。
