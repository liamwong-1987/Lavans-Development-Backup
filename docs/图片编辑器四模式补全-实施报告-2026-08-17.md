# 图片编辑器四模式补全实施报告

- **日期**：2026-08-17
- **模块**：复色画布（canvasStudio.js）
- **类型**：画布复刻——图片编辑器第二阶段（遮罩/画笔/宫格/缩放）

## 结论

复色画布图片编辑器从「裁剪 + 扩图」两个模式，补齐到 **6 个模式**（裁剪/扩展/遮罩/画笔/缩放/宫格）。对照大神画布（hero8152/Infinite-Canvas）的核心逻辑复刻，代码落地、语法通过、函数闭环。

## 实现内容

### 1. 新增 4 个模式（HTML + JS + CSS）

| 模式 | 功能 | 关键实现 |
|------|------|---------|
| **遮罩 mask** | 画笔涂白色区域 → 转黑白遮罩图 → 上传 | `canvasMaskCanvasFromDrawCanvas` 像素级转换（alpha>8 判定） |
| **画笔 brush** | 自由/矩形/椭圆/数字标签 4 种工具，彩色绘制合并原图 | `canvasDrawBrushShape`（矩形/椭圆）+ `canvasDrawNumberLabel`（圈号标签） |
| **缩放 resize** | 倍数 slider（5%~100%）缩放图片 | `applyCanvasImageResize`（canvas 高质量缩放） |
| **宫格 grid** | 预设 1×2~3×3 + 横竖线输入，切分多图 | `canvasGridSplitRects`（按行列切分） |

### 2. 绘制画布系统（遮罩/画笔共同依赖）

- `canvas-edit-draw-canvas` 覆盖在图片上，尺寸 = 图片自然尺寸，CSS 拉伸到显示尺寸
- 画笔拖拽：`canvasBeginEditDraw` / `canvasMoveEditDraw` / `canvasEndEditDraw`（pointer 事件 + setPointerCapture）
- 撤销/重做：`pushCanvasEditDrawHistory` / `undoCanvasEditDrawing` / `redoCanvasEditDrawing`（toDataURL 快照栈，上限 30）
- 笔刷：`canvasEditBrushSize`（遮罩/画笔各自独立 slider）+ `canvasBrushColor`（颜色选择器）

### 3. 模式分发

- `setCanvasImageEditMode`：6 模式切换，显示对应工具栏，隐藏裁剪框（遮罩/画笔/缩放/宫格模式）
- `applyCanvasImageEdit`：按模式分发到 6 个 apply 函数
- `openCanvasImageEditor`：打开时初始化绘制画布尺寸 + 清空撤销栈 + 绑定绘制事件

## 精简说明（与大神差异）
