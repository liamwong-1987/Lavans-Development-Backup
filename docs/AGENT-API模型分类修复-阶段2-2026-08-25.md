# AGENT / API 模型分类修复：阶段 2 断点

## 目标

修复 API 设置中“视频模型被放进 LLM，因而无法被画布或 AGENT 使用”的根因；本阶段只处理后端模型拉取与能力分类。

## 已确认决定

- APIMART 使用官方模型元数据分类，读取 `/v1/models?expand=category`。
- 分类正式包含 `image`、`chat`、`video`、`audio`、`unknown` 五类。
- 官方分类优先；缺少官方分类时，才使用输出能力与已知模型族名称推断。
- 无法可靠判断的模型必须进入 `unknown`，不得默认塞进 LLM。
- 本阶段不改模型保存/迁移、不改前端分类界面、不改真实媒体提交协议。
- Provider、API Key、当前已保存模型、AGENT 与一键复色数据均不得被重置或自动切换。
