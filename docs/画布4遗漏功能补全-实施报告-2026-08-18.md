## 补全内容

复色画布（canvasStudio.js）相对大神画布（hero8152/Infinite-Canvas）的 4 个遗漏功能，全部补齐。

| 功能 | 改动 | 入口 |
|------|------|------|
| **输出对比滑块** | HTML + JS + CSS | 双击图片节点打开灯箱，原图vs结果左右拖动对比 |
| **节点右键菜单** | HTML + JS + CSS | 节点右键→快速连线/添加输入输出 |
| **输出提示词面板** | HTML + JS + CSS | 灯箱底部显示提示词+复制按钮 |

## 具体实现

### 1. 输出对比滑块
- 灯箱 HTML：`canvas-output-lightbox`含对比容器（原图左半/结果右半）+滑动条+手柄
- JS：`openCanvasStudioLightbox(url, originalUrl, nodeId, prompt)`、`closeCanvasStudioLightbox`、`bindCanvasStudioCompareSlider`
- 双击图片节点 → 弹出灯箱，有原图+结果时自动显示对比模式
- 双击对比区域切换对比/单图模式

### 2. 节点右键菜单
- HTML：`canvas-link-create-menu`（快速连线）+ `canvas-node-input-menu` / `canvas-node-output-menu`（输入/输出菜单）
- JS：`openCanvasLinkCreateMenu` / `openCanvasGeneratorNodeMenu` / `closeCanvasNodePortMenu`
- 生成节点右键 → 显示"添加输入"+"添加输出"两个菜单
- 提示词/图片/LLM节点右键 → 快速连线菜单
- 点击菜单项自动创建节点并连线

### 3. 输出提示词面板
- 灯箱底部显示提示词文本 + 复制按钮 + 重新运行按钮
- 复制：`navigator.clipboard.writeText`
- 重新运行：调用 `canvasStudioGenerate(nodeId)`

### 4. 下载全部/重新运行
- 下载按钮：创建 `<a>` 元素触发下载
- 重新运行：调用 `canvasStudioGenerate(nodeId)` 重新生成
