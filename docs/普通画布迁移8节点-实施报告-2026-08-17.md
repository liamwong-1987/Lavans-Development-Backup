## 三、改动内容（仅 `canvasStudio.js`，+104/-3）

1. `canvasNodeTitle`：新增 8 个中文标题映射。
2. `canvasNodeSizeLimits`：补 8 个节点默认尺寸（对齐契约，如 ltxDirector 1000×800）。
3. 创建菜单 `smart-create-menu`：从 5 张卡片扩到 13 张。
4. 数据结构：新增 `canvasClassicNodeTypes` / `canvasClassicNodeDefaults`，逐字段对齐智能画布 `CLASSIC_NODE_DEFINITIONS`。
5. 节点 body 渲染：`canvasClassicNodeBody` 分派 8 个子函数，各渲染核心字段。
6. 运行"未接入"：`canvasComposerContext` 对 8 个节点返回 `canRun:false` + "未接入"提示。
7. 字段读写：新增 setter（select/number/textarea 防抖）。

## 四、关键设计说明

- **comfy 字段冲突**：Comfy 契约的 `width/height`（图片尺寸）与画布节点几何 `node.width/height` 重名，已在普通画布内改名 `comfyWidth/comfyHeight`，其余字段语义不变。这是唯一与契约字段名不一致处。
- **不接 API 的铁证**（QA 重点核实）：4 条运行路径（Composer 状态判定 / Composer 运行按钮 / 一键级联 / 级联逐轮）全部被 `canvasIsGeneratorNode` / 白名单 / unsupported 拦截，`canvasStudioGenerateAsync`（真正发 `/api/canvas/tasks` 的入口）对这 8 个节点**不存在可达调用链**。
