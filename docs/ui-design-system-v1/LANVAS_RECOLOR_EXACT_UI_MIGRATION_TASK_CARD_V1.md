# Lavans 一键复色精确 UI 迁移任务卡 V1

更新时间：2026-08-24  
当前状态：T1～T6 与 14 个正式场景已完成自动、安全和实际软件 100% 人工验收；第④档只做最终记录与回归收口。  
用户验收硬门槛：左侧栏与一键复色全部界面必须与已确认 HTML／效果图一致；“功能可用但视觉接近”不算通过。

## 1. 本轮目标

把已确认母版的真实结构迁入生产界面，同时保留阶段 A～G 已有的队列、安全、上传、历史、导出、裁剪、取色、费用与恢复能力。

本轮不是继续给旧页面换色，也不是在旧弹窗上追加样式；必须让生产页面使用与母版一致的布局层级、尺寸、视觉语言和场景结构。

## 3. 本次失败的结构性根因

### 3.1 全局左侧栏仍是旧外壳

生产 `resources/frontend/index.html` 和 `lanvas-shell.css` 仍保留悬停展开、固定／折叠、旧宽度与多轮覆盖规则。最终覆盖值把左栏收窄为约 188 px、导航文字压回 14 px、致敬图标推到最右，直接违反已确认的 212 px／16 px／22 px 规格。

### 3.2 一键复色仍被整页缩放

`smart-canvas-core/theme.js` 会根据内容宽度给 iframe 页面做整体 transform 缩放。一键复色没有退出该机制，因此窗口变窄时文字、图标、弹窗和所有间距一起缩小。已确认规则是不缩小字体：优先折叠右侧检查栏并收纳次要内容。

### 3.3 弹窗使用通用容器拼装

`app.js` 的 `openRecolorOverlay`、`askRecolorConfirmation` 及多处动态字符串把不同场景塞进同一通用白框；开始、重做、导出、裁剪、取色、历史和全屏对比没有使用最终 V3 的场景专属结构，所以只改 CSS 不可能精确复刻。

### 3.4 样式层叠已失去单一权威

`lanvas-pages.css` 累积了多轮 Phase 3／F 覆盖；`index.html` 还有内联旧样式，`lanvas-shell.css` 又在尾部重新覆盖尺寸。生产页面没有一个能稳定代表已确认母版的权威样式层。

### 3.5 “改绑模型”只有视觉场景，尚无安全业务接口（历史根因，已关闭）

当前生产代码中没有找到一键复色专用的待生成任务改绑接口。Terra 可以精确还原该弹窗的视觉状态，但不得在 UI 迁移阶段临时写一个会修改运行中、已提交或已完成任务的接口。功能接通必须回到 Sol 做独立安全设计与无付费测试。

关闭结果：后续第②档已由 Sol 完成预览／确认接口、一次性预览令牌、请求幂等、事务内资格复核、保存失败回滚与保持暂停合同；只允许零调用、零费用、未领取、未提交的 pending 任务改绑，运行中、远端未知、已完成及已有费用任务保持原样。正式 UI 只从 `model_unavailable` 暂停状态进入，不自动弹出，不调用 Provider。

## 4. 不变边界

### 4.1 必须保留的既有功能

- 与画布共用全局 API 设置，但复色任务、历史与画布业务数据隔离。
- 单一 FIFO 队列、运行中追加、默认 8 并发且可设 3～8。
- 系统性错误整批暂停，非付费健康检测恢复后自动继续，并保留手动继续。
- 任务状态、远端未知任务保护、重做新版本后安全替换、单张删除 5 秒撤销。
- 隐藏式整卡上传，支持点击、拖放、粘贴；模板优先全组合并按上传批次追加到末尾。
- 参考色本地取色、手动 HEX、同批真实裁剪；相关元数据不进入提示词和生成 API。
- 复色独立历史、按需导出与已导出标识、三图对比、右栏拖动对比线与任务日志。
- 费用、调用次数、批次锁定提示词和单价的同一数据来源。

### 4.2 本轮禁止事项

- 不改阶段 A～G 后端业务语义，不重写任务引擎。
- 不运行真实 Provider，不上传用户素材，不调用付费 API。
- 不新增导航名称、业务页面、功能入口或视觉语言。
- 不用“看起来差不多”的新组件替代已确认母版。
- 不保留可见的旧弹窗作为兜底路径。
- 不对一键复色做整页缩放，不以缩小字体解决 1280 px 适配。
- 不混用 Emoji、手绘 SVG 或其他图标库；生产必须使用自托管 Phosphor Duotone。
- 不在 Terra 视觉迁移阶段擅自实现任务改绑后端。

## 5. 生产架构决策

### 5.1 可见结构采用母版 DOM，业务继续复用现有接口

不是删除现有功能重写一套，而是：

1. 以母版的 HTML 层级建立生产可见 DOM。
2. 把现有接口、状态和事件函数逐项绑定到母版节点。
3. 每迁完一个入口，删除或永久隐藏其旧的可见路径，避免双入口和状态分叉。
4. 仅在所有 JavaScript 引用完成迁移后，才移除无用兼容节点。

### 5.2 建立两个最终权威样式层

建议新增并最后加载：

- `resources/frontend/lanvas-shell-v3.css`：全局顶栏、212 px 左侧栏、导航、致敬区、全局深浅主题材质。
- `resources/frontend/lanvas-recolor-v3.css`：一键复色主工作台、内窄栏、任务列表、右侧检查栏、14 个正式场景。

两个文件必须页面作用域明确。`lanvas-pages.css` 可继续服务其他旧页面，但不得再覆盖一键复色 V3。禁止继续往旧文件尾部堆“修复补丁”。

### 5.3 图标资产本地化

把已确认母版使用的 `docs/ui-design-system-v1/assets/Phosphor-Duotone.woff2` 复制到正式前端资产目录并由生产 CSS 本地引用。正式应用不依赖在线字体或图标 CDN。

### 5.4 一键复色退出整页缩放

给 `recolor.html` 设置页面级缩放退出标记，例如：

```html
<html lang="zh-CN" data-studio-scale="off" data-studio-fit-scale="off">
```

全局壳的缩放系统可暂时保留给其他旧页面，但一键复色必须按真实像素布局。1280 px 时自动折叠右栏，不能整体缩小。
