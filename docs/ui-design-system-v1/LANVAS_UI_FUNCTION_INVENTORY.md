# Lavans 全软件 UI 改造：功能保留清单

本清单受 `LANVAS_UI_DECISION_REGISTER_V1.md` 约束。任何效果图或视觉实现均不得删减、改名或替代这里记录的现有功能；发现清单与生产功能不一致时，以生产可观察功能为准并先更新清单。

本清单用于 UI 改造后的逐项回归，不代表新增功能。

| 区域 | 必须保留的功能 |
| --- | --- |
| 全局外壳 | 本地功能、文生图、细节增强、图片编辑、角度控制、在线生图、GPT 对话、无限画布、素材库、一键复色、API 设置、更多设置、深浅模式、语言、工作流设置、项目主页 |
| 一键复色 | 模板上传、参考色上传、自动配对、扫描配对、生成、筛选、排序、批量选择、下载、继续生成、重置、清空任务、清空日志、刷新、预览、详情三图、左右键切换、单任务重做、删除、失败诊断 |
| API 设置 | 平台管理、请求地址、密钥、验证、模型拉取与选择、生图/聊天/视频模型、CLI 设置、RunningHub、ModelScope LoRA 和自定义平台配置 |
| 画布与 Agent | 节点创建、连接、上传、素材引用、右栏检查、Skill 卡、资料提交、勾选问询、十阶段节点、审核、暂停、继续、取消、局部重做、版本与恢复账本 |
| 本地生成工具 | 各页面原有上传、提示词、模型、尺寸、参数、生成、历史、预览、下载、保存和复用能力 |
| 素材与项目 | 项目、画布卡、回收站、素材分类、搜索、筛选、预览、重命名、复制粘贴、下载、ZIP、删除与恢复 |

## 一键复色页面级视觉检查

- 上传区、统计栏、任务工具栏、任务列表、底部操作区、右侧预览和日志保持可见、可读、可操作。
- 任务列表只显示模板图与生成图；参考色不在列表中出现。
- 当前阶段样式若与确认效果图不一致，后续以阶段三页面专属还原为准。
