状态：浅色与 G 近黑灰深色 14 个正式产品场景已全部通过最终视觉验收；代码只读审计与迁移清单已完成，等待按小阶段实施。  
范围：一键复色产品体验、页面 UI、任务状态与实现边界。  
代码状态：尚未修改生产代码；实施顺序见 `LANVAS_RECOLOR_CODE_MIGRATION_PLAN_V1.md`。  

交互母版：`LANVAS_RECOLOR_LIGHT_MASTER_V0.html`。最新浅色确认图：`LANVAS_RECOLOR_LIGHT_MASTER_V2.png` 及四个对应 V2 弹窗。

## 1. 权威与使用方式

本文档是一键复色改造的唯一干净设计规格。实施时不得再从旧效果图、旧修复报告或旧页面规范中拼接需求。

发生差异时按以下顺序处理：

1. 用户之后明确确认的新决定。
2. 本文档。
3. `LANVAS_UI_DECISION_REGISTER_V1.md` 中未被本文档覆盖的全软件边界。
4. `LANVAS_DESIGN_SYSTEM_V1.md` 中的全局品牌令牌。
5. 当前生产代码，只用于识别需要迁移的真实能力，不用于否定本文档已确认的新行为。

旧文档继续作为历史证据，不再作为一键复色目标界面的直接实施依据。

## 2. 全软件视觉设计样板定位

一键复色的 UI 视觉设计是 Lavans 第一份完整视觉样板。成为样板的是界面的配色、文字、字体、图标、按钮、弹窗、状态表达、组件质感和深浅色规则，不是一键复色的功能。

它先验证以下全软件能力：

- 冷中性深浅主题与深紫品牌强调。
- MiSans VF 中文界面和 JetBrains Mono 任务信息。
- Phosphor Icons Duotone 图标语言。
- 主按钮、次级按钮、图标按钮和危险按钮。
- 上传、筛选、列表、日志、空态、加载态、错误态和弹窗。
- 键盘操作、焦点、禁用、悬停、按下和减少动态效果。
- 高密度工作区在不同窗口宽度下的稳定布局。

后续页面可以复用这些视觉令牌、设计语言和组件质量。不得把一键复色的上传配对、批量生成、并发、任务队列、重做、导出等功能视为全软件功能样板，也不得机械复制其三栏结构或任务列表。其他页面保留自己的功能，根据真实业务逐页判断布局是否需要调整。

## 3. 设计判断

页面类型：高密度创作生产工作台。  
主要用户：需要一次处理几十到上百张商品图，并快速人工判断结果的创作者。  
核心感受：安静、精确、可靠，有创作工具的能量，但不喧闹。  
设计名称：紫域工作台。

设计参数：

- 设计变化度：4/10。结构清楚、稳定，不追求实验性布局。
- 动效强度：3/10。动效只用于反馈、状态和层级变化。
- 信息密度：8/10。高密度但不拥挤，不通过缩小中文字体塞内容。
- 品牌识别：10/10。深紫是唯一装饰性强调色。

## 4. 产品边界

### 4.1 与画布共享的内容

- 全软件唯一 API 设置。
- Provider、模型列表、密钥和调用能力。
- 全局深浅主题。
- Lavans 品牌令牌、字体和图标。

画布完成 API 设置后，一键复色直接可用。一键复色不建立独立 API 设置、独立 Provider 存储或第二份密钥。

### 4.2 与画布隔离的内容

- 上传素材。
- 配对关系。
- 任务和队列。
- 生成结果。
- 日志和运行记录。
- 缓存、临时文件和导出记录。

### 4.3 明确不做

- 不提供圈选或 Mask。
- 不在本地调色、修图或拼接。
- 不自动判断色差。
- 不显示质量通过、色差数值或成功率。
- 不自动重做。
- 不要求逐张确认通过。
- 不保存可切换的历史结果版本。

## 5. 全局外壳

### 5.1 全局左侧栏

全局左侧栏属于 Lavans，不属于一键复色内部。

- 导航名称、顺序、入口和路由保持现有产品定义。
- 当前页使用 `Swatches` 图标和深紫选中态。
- 全局左侧栏宽度固定为 212 px；顶部品牌区与侧栏共用同一右边界，工作区从左侧栏外 16 px 开始。
- 导航文字使用 16 px，图标使用 22 px，菜单行高 42 px；“本地功能”使用 16 px 文字、20 px 图标和 44 px 高度。
- “角度控制”必须显示同一套 Phosphor Duotone 图标，不得只剩无图标文字。
- 左下角保留原作致谢与 GitHub 链接；致谢文字保持 11 px，不随导航放大。GitHub 图标紧跟文字，间距 8 px，不使用左右两端分散排列。
- 一键复色内部不重复提供主题切换或 API 设置入口。

### 5.2 一键复色内层工具栏

内层工具栏宽度 64 px，只放图标，不承担第二套全软件导航。

固定为 8 个真实功能入口，不放纯装饰图标，也不放“功能开发中”空壳：

| 功能 | 图标 | 行为 |
| --- | --- | --- |
| 提示词设置 | TextAa | 打开提示词类型、主提示词和本批次附加要求 |
| 历史结果 | ClockCounterClockwise | 打开一键复色独立历史图库 |
| 展开／收起上传区 | UploadSimple | 控制两个上传卡片占用空间 |
| 聚焦任务搜索 | MagnifyingGlass | 把输入焦点放到任务搜索框 |
| 只看生成中 | SpinnerGap | 直接应用“生成中”筛选 |
| 只看失败 | WarningCircle | 直接应用“失败”筛选 |
| 打开最新生成结果 | ImageSquare | 打开最近一张生成图的三图对比 |
| 右侧检查栏开关 | SidebarSimple | 展开或收起右侧检查栏 |

图标使用 Phosphor Duotone。没有对应内容时，相关入口置灰且不可点击，不弹空壳提示。

## 6. 页面总体布局

### 6.1 桌面结构

一键复色内部保留左、中、右结构：

1. 内层图标工具栏。
2. 中央主工作区。
3. 可调宽、可折叠的右侧检查栏。

中央区域是绝对主工作区，常态占一键复色可用宽度约 72% 到 80%。

### 6.2 中央纵向结构

从上到下固定为：

1. 页面标题和四项统计。
2. 两个大面积上传框。
3. 任务工具栏和固定表头。
4. 连续滚动任务列表。
5. 固定底部操作栏。

上传区允许收起。任务表头和底部操作栏始终固定，只有任务列表滚动。

### 6.3 右侧检查栏

- 默认宽度 360 px。
- 可拖动范围 320 到 520 px。
- 可折叠到 0。
- 记住上次宽度和折叠状态。
- 上半部是模板图与生成图对比。
- 下半部是任务日志。

### 6.4 窗口适配

- 1920×1080 是主验收尺寸。
- 1440×900 必须保持任务列表和底部按钮完整可用。
- 1280 px 以下默认允许折叠右栏，不缩小中文字体。
- 宽度不足时优先缩短辅助说明、收起上传区和折叠右栏。
- 不允许任务操作按钮、底部按钮或错误原因被裁掉。

### 7.1 紫域渐变与流光材质

所有承担品牌识别、当前选中或主要操作的紫色按钮与图标，统一使用紫域渐变与紫白流光语言。深浅主题保持相同的语义、结构、尺寸、图标、位置、触发方式和动效节奏，但允许根据背景明暗使用不同材质强度；同构不等于强制使用相同深紫底面。

按视觉层级分为三档：

1. **一级主操作**：开始生成、暂停生成、保存并设为当前、确认并开始、重做等每个区域唯一主按钮。使用完整深紫到亮紫渐变和持续缓慢斜向流光；悬停时流光适度加快。
2. **二级选中控件**：当前全局导航、内层窄栏当前图标、筛选标签、日志标签、提示词当前类型、并发设置等。浅色主题使用淡紫低对比渐变、深紫识别标记和低强度单次流光；深色主题使用更完整的深紫渐变、白色前景和较清晰的单次流光。两者选中、悬停或点击时均只扫光一次，不永久循环。
3. **三级品牌与小图标**：Lavans Logo 和紫色功能图标。Logo 每约 8 秒出现一次低强度流光；小图标保留深紫到亮紫渐变，只在悬停或所属控件触发时扫光。

以下内容明确不套用品牌流光：普通紫色文字、表格装饰线、日志圆点、非交互色块以及成功、警告、失败状态。状态色继续分别使用绿、琥珀和红，不能被紫色渐变覆盖。

## 9. 页面标题与统计

页面标题为“一键复色”。不再保留页面内部独立主题按钮或顶部重置按钮。

四项统计固定为：

1. 任务总数。
2. 已生成。
3. 生成中。
4. 失败。

四项状态统计右侧保留“批次费用”入口。入口显示当前累计费用和实际 API 调用次数，例如 `¥2.32 · 29 次 API 调用`，整块区域都可点击，并带明确的展开图标。它不是第五项任务状态统计，也不显示成功率、百分比或确定性进度条。

点击后打开正式设计的“任务执行汇总”弹窗，显示：总任务数、已生成、失败、中断、累计中断次数、总耗时、平均单任务耗时、API 实际调用次数、当前批次单价、小计、总费用、开始时间和结束时间。运行中允许查看，结束时间显示“生成中”，其余数据按当前实际值更新。

当用户在提示词设置中修改了单次调用价格，而当前批次已经开始时，汇总顶部同时显示“当前批次单价（已锁定）”和“下一批单价（手动设置或系统默认）”。不得用新价格倒算已经发生的调用费用。

统计规则：

- 已生成只表示 API 已返回图片。
- 不显示成功率。
- 等待任务只进入任务总数，不单独占统计卡。
- 任务处于 5 秒撤销期时仍计入统计。
- 正式删除后从统计移除。
- 点击已生成、生成中、失败可以切换对应筛选。

## 10. 上传区与任务创建

### 10.1 上传框

顶部使用两个等宽大面积上传框：

- 模板图。
- 参考色。

每个上传框必须满足：

- 文件输入控件在视觉上完全隐藏，不显示嵌套的小型“点击或拖放上传”框。
- 整张大卡片都是上传命中区；点击任意空白位置打开系统文件夹选择器。
- 整张卡片接收图片拖入，拖入时使用边框和低透明紫色背景反馈。
- 支持 `Ctrl+V` 粘贴剪贴板图片。页面同时存在两个上传区时，图片进入用户最后点击或聚焦的上传卡片。
- 当前粘贴目标使用克制的淡紫焦点提示，不使用阻断弹窗。
- 空状态显示标题、支持格式和上传动作。
- 已选状态显示第一张缩略图、文件总数、继续添加、移除全部。
- 已选后整张卡片仍保持点击、拖入和粘贴能力；“继续添加”不是唯一上传入口。
- 点击第一张缩略图或文件总数打开轻量素材抽屉；抽屉只负责查看、放大和逐张移除，不重复提供另一套上传入口。
- 逐张移除素材时，同步移除由该素材形成但尚未开始的关联任务；已经运行或已有结果的任务不受影响。

### 10.2 自动组合

模板图和参考色都存在后，普通直接添加路径自动创建任务，不再显示“扫描配对”按钮。选择“裁剪后添加”时，素材先停留在裁剪预览中，只有用户确认裁剪结果后才自动创建任务；取消裁剪不上传也不创建任务。

不保留独立“上传素材”或“智能配对”页面，不展示配对矩阵，也不要求用户再次扫描或确认组合。

初始顺序：

1. 模板图 1 × 全部参考色。
2. 模板图 2 × 全部参考色。
3. 后续模板依次排列。

运行中新增模板图或参考色形成的新任务，统一追加到列表末尾，不移动旧任务。

允许相同模板和相同参考色重复上传并主动创建独立任务。系统不得以“已存在”为由阻止。

### 10.3 移除全部

上传区“移除全部”只处理：

- 当前上传区素材。
- 由这些素材形成且尚未开始的关联任务。

运行中和已生成任务不受影响。它们必须保留自己的输入快照，确保任务详情、全屏颜色图、恢复和导出仍可使用。

## 11. 任务列表

### 11.1 工具栏

任务工具栏包含：

- 搜索。
- 排序。
- 全部、已生成、生成中、失败四个快捷筛选。
- 当前任务数量。

不提供分页、复选框或批量勾选工具栏。

### 11.2 分组

列表仍是一个连续列表，但按模板显示轻量分组标题：

`模板名 · N 种颜色`

分组标题只承担阅读定位：

- 在每个模板组第一条上方出现。
- 滚动时短暂吸附任务列表顶部。
- 不可折叠。
- 不创建独立列表或卡片容器。
- 新增任务仍按追加规则放在末尾。

### 11.3 任务行

标准桌面一屏显示约 5 到 6 行。建议行高 112 到 116 px。

字段顺序：

1. 稳定任务编号。
2. 模板图缩略图。
3. 方向箭头。
4. 生成图缩略图或状态占位。
5. 任务名称、参考色色块、参考色名称和实际模型悬停信息。
6. 状态和失败原因。
7. 重做。
8. 删除。

列表只显示模板图和生成图两张缩略图。参考色只显示小色块，不显示第三张参考图缩略图。

缩略图建议：

- 尺寸约 136×78 px。
- 完整保留可判断色差的可视面积。
- 图片圆角 10 px。
- 点击模板图或生成图进入全屏三图对比。

任务位置一旦创建必须稳定。并发返回、失败、重做和追加都不能让旧任务跳动。

### 11.4 行内状态

任务状态固定为：

- 等待生成。
- 生成中。
- 已生成。
- 生成失败。
- 已删除。

已删除任务在界面立即隐藏，5 秒撤销期结束后正式删除。

生成中不显示百分比或确定性进度条。使用：

- 状态文字旁 16 px 旋转活动图标。
- 任务行顶部一条很细的紫色流光，从左向右循环。

流光只表达正在活动，不表达完成比例。

失败行保持原位置，显示一行简短中文原因。完整错误在悬停提示和日志中查看。普通单任务失败不自动重试，后续任务继续。

## 12. 右侧检查栏

### 12.1 选择规则

- 点击任务后锁定该任务。
- 其他任务完成不得抢走当前选择。
- 用户尚未手动选择时，显示最新生成结果。
- 折叠再展开后，恢复同一任务和对比位置。

### 12.2 双图对比

右栏只显示模板图和生成图。

- 使用同一画框和可拖动垂直对比线。
- 生成前保留相同尺寸占位区。
- 占位文字根据状态显示等待生成、正在生成或生成失败。
- 正在生成时使用低强度紫色活动流光。
- 不显示参考色图、色差、质量通过或自动质检。

### 12.3 日志

日志位于右栏下半部：

- 默认显示最近记录。
- “查看全部”打开完整日志。
- 默认文案使用普通用户能理解的中文；请求标识、原始错误和开发参数折叠在技术详情中。
- 系统错误使用红色并固定在最上方。
- 支持刷新和清空日志。
- 清空日志只清日志，不清任务、结果或上传素材。

## 13. 全屏三图对比

以下入口进入同一个全屏对比：

- 右侧预览图。
- 任务列表模板图。
- 任务列表生成图。
- 历史结果中的生成图。

全屏固定显示：

1. 模板图。
2. 生成图。
3. 模型实际收到的颜色参考图。没有裁剪时显示上传原图；使用裁剪后添加时显示裁剪图，并提供“查看原图”入口。

三张图使用等宽图片区，完整显示，不裁切。比例不同时以统一背景承接空余空间。

支持：

- 鼠标滚轮缩放。
- 拖动查看放大区域。
- 左右方向键切换上一条和下一条任务。
- Esc 关闭。
- 底部紫色“重做”按钮。

提交重做后全屏不关闭：

- 旧生成图继续显示。
- 旧图覆盖“正在重做”的紫色活动层。
- 用户可以立即切换并继续查看其他任务。
- 新图成功后原位替换。
- 新图失败时保留旧图并显示失败原因。

## 14. 底部固定操作栏

底部只保留三个业务操作：

1. 生成主按钮。
2. 导出结果。
3. 彻底清空。

### 14.1 生成主按钮

同一位置根据状态变化：

- 无任务：开始生成，置灰。
- 有等待任务：开始生成。
- 正在运行：暂停生成。
- 已暂停：继续生成。
- 全部结束：生成完成，置灰。
- 新任务加入：恢复开始生成或继续运行状态。

并发设置图标紧邻主按钮，作为主按钮的附属设置，不算第四个业务操作。

### 14.2 导出结果

- 没有已生成结果时置灰。
- 有结果时打开正式导出弹窗，默认选择全部最新生成结果。
- 可按上传批次、参考色、模板图和仅未导出进行多选或组合筛选。
- 不受主任务区当前搜索和筛选影响，只有导出弹窗内的条件生效。
- 运行中允许导出。

运行中导出完成提示：

`已导出当前完成的 N 张图片，剩余任务仍在生成。`

### 14.3 彻底清空

彻底清空删除一键复色内部全部数据：

- 上传素材。
- 配对关系。
- 任务和队列。
- 生成结果。
- 一键复色历史结果及其索引。
- 缓存和临时文件。
- 日志。

不得触碰画布数据、全局 API 设置或全局主题。

## 15. 生成确认与并发设置

### 15.1 开始生成确认弹窗

点击开始生成后打开正式设计弹窗，不使用浏览器原生确认框。

信息顺序：

1. 标题“确认开始生成”。
2. 任务数量。
3. 从全局 API 设置读取的 Provider 和模型。
4. 当前并发数。
5. 预计 API 调用次数。
6. 当前模型支持时显示尺寸和质量。
7. 取消和“确认并开始”按钮。

默认焦点在取消。确认并开始是弹窗内唯一紫色主按钮。

弹窗不提供独立密钥、Provider 存储或复色专用 API 设置。

弹窗必须读取等待任务自己的模型快照，不能用当前全局模型冒充整批模型。只有一种模型时显示模型名和任务数；存在多种模型时显示“共 N 个模型”，并逐项列出模型名和对应任务数。

### 15.2 并发设置

- 范围：3 到 8。
- 首次默认：8。
- 记住上次设置。
- 修改立即生效。
- 从低值调高时，立即补足空闲并发位。
- 从高值调低时，不中断已运行任务，等待运行数量自然降到新上限。

## 16. 模型与任务快照

任务创建时固定以下信息：

- Provider。
- 模型。
- 支持时的尺寸和质量。
- 模板输入快照。
- 颜色参考输入快照。
- 创建时间。
- 唯一任务编号。

任务进入队列后，即使用户在全局 API 设置切换模型，该任务仍使用创建时模型。切换只影响之后创建的新任务。

任务不得复制或长期保存 API 密钥、账号凭证和余额信息。提交时实时读取全局 API 设置中的最新有效密钥和可修复接口地址；任务快照只锁定 Provider、模型、尺寸、质量和生成输入等业务参数。

参考图输入快照与本地 HEX 元数据分开管理：原图或裁剪图属于实际生成输入，任务创建后锁定；HEX 只用于界面和导出管理，可在生成前后免费修正并同步显示，不改变输入快照、不触发 API。

列表不增加模型列。状态悬停和右侧详情显示实际模型。

## 17. 队列与执行规则

### 17.1 唯一队列

普通任务和人工重做进入同一个 FIFO 队列，严格按实际进入时间执行。

- 人工重做不插队。
- 多张重做按点击顺序加入。
- 重做与普通任务共享并发上限。
- 运行中新增任务自动加入当前队列。
- 暂停时新任务和重做只入队，不执行。

### 17.2 单次调用

每次普通生成或重做只调用模型生成一次，然后停止。

- 不进行自动 QC。
- 不根据色差自动纠正。
- 不自动追加重试轮次。
- 网络层是否发生重试必须记录实际调用次数和费用，不能把多次网络调用描述成一次。

当系统无法确认服务商是否已经收到生成请求时，禁止自动再次提交。系统先查询远端结果；仍无法确认时将任务标记为“结果确认中”并暂停领取新任务，交给用户处理，避免重复扣费。只有明确确认请求未提交成功时才允许重新发送。生成和重做确认统一提示“预计 1 次 API 调用；无法确认的网络异常会暂停，不会擅自重复提交”。

### 17.3 普通失败

单张内容、超时或偶发生成错误：

- 当前任务标记生成失败。
- 保持原位置。
- 显示普通中文原因。
- 继续执行后续任务。
- 不自动重试。

### 17.4 主状态与运行标记

用户界面主状态仍固定为等待生成、生成中、已生成、生成失败、已删除。后台另设运行标记保存正在重做、待删除、系统暂停、远端取消中和远端结果未知，不得把这些过程覆盖进主状态字段。运行标记只在需要时作为辅助文字或活动层显示，不新增任务筛选；已生成任务进入重做时仍保留可预览、可导出的旧结果。

## 18. 单张重做

### 18.1 重做确认

每次点击重做都打开正式费用确认弹窗：

1. 标题“确认重新生成”。
2. 当前任务缩略图。
3. 当前任务实际模型。
4. “本次将产生 1 次新的 API 生成任务”提示。
5. 新图成功后替换旧图，失败保留旧图的说明。
6. 取消和“确认重做”。

默认焦点在取消。关闭或按 Esc 不调用 API。

### 18.2 非阻塞连续操作

确认一张重做后：

- 该任务立即生成或加入队列。
- 弹窗立即关闭。
- 用户无需等待，可以继续查看并重做其他图片。
- 只有当前任务的重做按钮被禁用。
- 同一任务在重做等待或运行期间不能再次重做。
- 其他任务重做按钮始终可用。

### 18.3 最新结果替换

- 重做期间临时保留旧图。
- 新图成功后原子替换旧图，并删除旧结果。
- 重做失败继续保留旧图。
- 界面和导出始终只使用一张最新成功结果。

## 19. 删除与撤销

删除在等待、生成中、已生成、生成失败和正在重做状态下均可使用。

交互：

1. 点击后任务立即从列表隐藏。
2. 页面底部显示 5 秒撤销提示。
3. 5 秒内撤销，恢复删除前状态。
4. 超时后正式删除任务记录、生成结果和相关缓存。
5. 保留原始上传素材。

正在调用 API 时：

- 系统尝试取消远端任务。
- 服务商不支持取消时，明确提示本次调用可能仍产生费用。
- 迟到结果直接丢弃。
- 已删除任务不得重新出现。

删除不再使用确认弹窗，因为 5 秒撤销是主要误触保护。

## 20. 暂停、系统故障与恢复

### 20.1 用户暂停

点击暂停生成后：

- 不再领取新任务。
- 已经提交给 API 的任务继续完成。
- 等待任务保持等待。
- 新增任务和重做只进入队列。

### 20.2 系统性错误

以下问题出现一次并确认后立即暂停整批：

- 密钥失效。
- 余额不足。
- 模型不可用。
- 接口地址错误。
- 同等级全局配置问题。

界面在任务列表顶部显示红色状态条，包含：

- 普通中文原因。
- 当前自动检测状态。
- 立即检测。
- 继续生成。

不使用阻断式错误弹窗，不显示原始 JSON。

### 20.3 自动恢复

- 只使用不产生图片生成费用的健康检查。
- 连续两次确认恢复后自动继续。
- 用户可以手动点击立即检测或继续生成。
- 检测未通过时保持暂停。
- 服务商没有免费检查能力时，只能在配置变化或用户手动操作后检查，不得偷偷生成图片测试。

原任务绑定模型恢复后可以自动继续。若原模型已下架或永久不可用，系统不得偷偷切换模型；必须提供一次正式确认，只允许把尚未提交的任务改绑到用户选择的新模型。已提交、生成中和已完成任务不得改绑。

## 21. 关闭软件与恢复

有任务运行时关闭软件，显示两个选择：

- 缩小到后台继续生成。
- 暂停并退出。

意外关闭或电脑重启后：

- 恢复原任务列表和顺序。
- 未提交任务保持等待。
- 状态未知任务先查询远端状态。
- 只有确认未提交后才允许重新进入队列。
- 不得因为恢复流程重复调用和扣费。

## 22. 导出与命名

本规格中的“上传批次”和“执行批次”不是同一概念：

- 上传批次：一次添加素材并由此创建的一组新任务，用于导出筛选和追溯；运行中追加会形成新的上传批次。
- 执行批次：从首次确认开始生成到当前队列完成的一轮执行，用于锁定提示词和单价；该轮运行中追加的多个上传批次沿用同一个执行批次快照。

### 22.1 导出范围

- 底部仍只保留一个“导出结果”按钮；点击后打开正式导出弹窗，默认选择全部任务的最新成功结果。
- 用户可主动改为按上传批次、参考色、模板图或“仅未导出”筛选；条件支持多选和组合，并实时显示本次可导出数量。
- 主任务列表当前筛选不影响导出范围，只有导出弹窗内明确选择的条件生效。
- 失败、等待和正在生成且没有结果的任务不进入 ZIP。
- 重做期间仍可导出该任务旧的最新成功结果。
- 运行中导出只收集点击时已经完成的最新结果，剩余任务继续生成。

“上传批次”定义为一次添加素材并因此新创建的一组任务。后来追加素材产生的新任务属于新的上传批次，已有任务不移动也不改批次。批次选择项显示创建时间、模板数、参考色数和任务数，不使用 01、02 等纯编号。

导出成功后按结果版本记录“已导出”：任务列表和历史结果均显示标记，悬停显示最近导出时间和累计次数；允许重复导出。取消保存或导出失败不标记。重做成功生成新版本后，新版本恢复为未导出。

同一筛选类别内多选采用“任意一个”，不同筛选类别之间采用“同时满足”。点击确认导出时立即冻结结果编号和版本；打包期间后来完成或重做成功的结果不进入本次 ZIP。

HEX 修改后保留“图片曾导出”，同时标记“导出名称已更新”；“仅未导出”默认包含这类需要按新名称重新导出的结果。按新名称导出成功后清除该提示。

### 22.2 ZIP 名称

- 全部结果：`YYYYMMDD-全部复色结果.zip`
- 按上传批次：`YYYYMMDD-上传时间-上传批次-复色结果.zip`
- 按参考色：`YYYYMMDD-HEX-RRGGBB-复色结果.zip`
- 组合条件：`YYYYMMDD-筛选结果-N张.zip`

### 22.3 包内文件名

`模板名-HEX-RRGGBB-YYYYMMDD-HHmmss.扩展名`

发生同名冲突时追加 4 位短识别码。不得使用 01、02 等纯序号。

重复任务在界面和记录中使用创建时间与 4 位短识别码区分。

### 22.4 参考色裁剪与本地取色

参考色上传卡同时提供正常添加和可选的“裁剪后添加”。正常添加不弹裁剪；选择裁剪后添加时，先在该次上传的代表图上设置一次裁剪框，再按归一化比例应用到同批全部参考图。确认批量预览后才上传并创建任务；取消则不上传、不创建任务。比例明显不同的异常图片必须标出，允许单独调整或暂不添加，禁止静默错裁。

保留原始参考图；裁剪图用于本地取色和提交给 API。三图对比默认显示模型实际收到的裁剪参考图，并提供“查看原图”。没有裁剪时，两者是同一张图。

颜色识别完全在本机完成，不调用 AI、不调用生成接口、不产生 API 费用，也不依赖原文件名。系统默认提取 6 个代表色，显示更多时最多 12 个；用户可选择候选色、使用带邻域平均的吸管、直接输入 HEX 或恢复自动结果。同批构图一致时可把同一取色位置应用到全批，但每张图仍分别计算自己的 HEX。相同 HEX 可在导出选择器中归组，相近 HEX 不自动合并。

**吸出的 HEX 只作为管理与导出元数据：用于色块显示、搜索、筛选、分组、历史信息和导出命名。HEX 不写入提示词、不附加到 API 请求，也不参与模型生成或质量判断。** API 仍只接收模板图、实际参考图和原有提示词。因此取色错误不会改变生成图；用户可在生成前后免费修正 HEX，修正后同步更新任务、历史、筛选和之后的导出名称，不触发重做或新的 API 调用。若要改变生成图的真实颜色，必须更换或重新裁剪实际参考图后由用户主动重做。

参考图没有任何任务或历史结果引用后，才清理原图、裁剪图、取色数据和缩略图；“彻底清空”按既有规则清除全部一键复色内部资料。

## 23. 通知与反馈

### 23.1 全部完成

页面通知：

`本批次已完成：生成 N 张，失败 N 张。`

软件位于后台时同时发送系统通知，不播放声音。

### 23.2 按钮状态

- 无任务时开始生成置灰。
- 无结果时导出置灰。
- 操作进行中按钮显示活动状态并防止自身重复点击。
- 一个任务的活动状态不得锁住其他任务。

## 24. 提示词、历史结果与弹窗设计

### 24.1 提示词设置与批次锁定

提示词设置从内层工具栏打开，保留以下真实能力：

- 提示词类型列表、新建自定义类型、类型名称。
- 每种类型独立保存的主提示词。
- 当前正在使用的类型。
- 本批次附加要求、清空附加要求、恢复默认、字符计数和可手动修改的单次调用价格。

主提示词类型长期保存。用户首次点击开始生成时，把“当前类型主提示词＋本批次附加要求＋当前单次调用价格”锁定为本批次快照；运行中修改提示词或单价只影响下一批，当前批次后来追加的任务继续使用已锁定快照。整批结束后自动清空本批次附加要求，主提示词、当前类型和手动单价不清空。重做是一次新的 API 调用，但仍使用该任务所属批次的锁定提示词和单价快照。

执行批次只在等待、生成中和重做中任务全部为零，并完成一次原子关闭后结束。关闭完成前加入的任务继承当前执行批次快照；关闭完成后加入的任务属于下一执行批次，必须重新点击开始生成。

提示词弹窗左下角使用清晰的金额输入控件，按“元/次”显示，不要求用户换算成分。支持恢复系统默认价格。保存后必须同步到顶部费用入口、开始生成确认、单张重做确认和任务执行汇总；这些位置读取同一份价格设置，不建立第二份计费配置。

### 24.2 历史结果

历史结果是只属于一键复色的长期图库，与画布归档、素材、任务、结果、日志、缓存和索引完全不相通。

- 图库只展示生成后的复色图，不把模板图和参考色图作为图库卡片。
- 模板图和参考色图只作为三图对比的内部关联资源；多个结果共用时只保存一份，最后一个关联结果删除后再清理。
- 每个任务仍只保留最新一次成功结果，不建立可切换版本列表。
- 支持单张删除、多选删除、按批次删除和全部删除。
- 单张删除不弹确认；多选、批次和全部删除使用正式确认弹窗。
- 所有删除先同时从历史图库和当前已完成任务列表隐藏，并提供 5 秒撤销；撤销同时恢复两处。
- 5 秒结束后删除生成图、缩略图和索引，但不删除上传区里的模板图与参考色图。
- 删除后不保留“结果已删除”空壳，不自动重新生成，也不改变上传素材。

### 24.3 统一弹窗规则

本页至少包含以下正式弹窗或大面板：

1. 开始生成确认。
2. 单张重做确认。
3. 彻底清空确认。
4. 关闭软件时的运行任务处理。
5. 任务执行汇总。
6. 提示词设置。
7. 历史结果管理。
8. 多选、批次和全部历史删除确认。
9. 全屏三图对比。

共同规则：

- 不使用浏览器 `confirm` 或 `alert`。
- 大面板圆角 16 px。
- 使用遮罩和轻微背景模糊，但不过度玻璃化。
- 标题、核心事实、风险说明、按钮形成稳定层级。
- 默认焦点落在安全操作。
- Esc 等于取消。
- Tab 焦点限制在弹窗内部。
- 浅色和深色结构完全相同。

彻底清空弹窗使用危险色确认按钮，清楚列出删除范围、不可撤销和远端可能继续计费的风险，不要求输入确认文字。

## 27. 当前代码迁移要求

本节用于避免继续在旧结构上换色或隐藏元素。

### 27.1 前端结构

必须合并或移除：

- 页面内部主题切换。
- 顶部重置。
- 扫描配对按钮。
- 独立“上传素材”页面。
- 独立“智能配对”页面和配对矩阵。
- 与主页面重复的批量状态、结果输出和日志空壳页面。
- 任务复选框和批量勾选工具栏。
- 进度百分比和确定性进度条。
- 行内预览、下载和批量重试入口。
- 多套开始生成、暂停、继续和清理按钮。
- 仅为旧 JavaScript 保留的隐藏步骤、旧面板和隐藏按钮。
- 浏览器原生确认框和内联临时弹窗样式。

目标是建立一个清晰 DOM 和一个渲染入口，不继续依靠隐藏旧 DOM 加 CSS 覆写维持页面。

### 27.2 任务数据

任务至少需要稳定记录：

- 唯一任务编号。
- 队列进入序号。
- 创建时间和短识别码。
- 模板与参考色输入快照。
- 上传批次编号与执行批次编号，两者不得混用。
- 原始参考图、可选裁剪图、裁剪参数和模型实际使用的参考图标识。
- 可修改的本地 HEX 管理元数据；该字段不得进入提示词或 API 请求。
- 批次锁定的提示词类型、主提示词、附加要求和单次调用价格快照。
- Provider、模型、尺寸、质量快照。
- 等待、运行、已生成、失败、待删除、已删除状态。
- API 调用标识、实际调用次数和费用。
- 最新成功结果。
- 删除截止时间和远端取消结果。
- 历史结果索引，以及三图对比所需的模板图和参考色内部关联。
- 当前结果版本的已导出状态、最近导出时间和累计导出次数。

任务统计只把真实终态计入完成，不得把等待和运行中计入完成。

### 27.3 执行器

- 队列按进入序号 FIFO 领取。
- 运行中追加必须合并新任务编号，而不是只刷新旧任务状态。
- 并发使用 3 到 8 的实时设置。
- 暂停只停止领取，不中断已提交调用。
- 同一任务编号必须幂等，防止恢复或重复领取造成二次扣费。
- 业务上相同的素材组合允许拥有不同任务编号。

### 27.4 生成服务

- 删除自动 QC 决策和自动纠正循环对任务成功状态的控制。
- 不使用 Mask。
- 每次任务只执行一次模型生成。
- 只有 API 返回图片、下载完整、格式校验通过并成功原子保存后才标记已生成。返回后下载失败、格式损坏或保存失败均标记生成失败，同时保留实际调用和费用记录。
- 重做先写入临时新结果，成功后再原子替换旧结果。
- 重做失败不得清除旧结果。

### 27.5 删除与清空

- 单任务删除使用 5 秒两阶段删除。
- 运行中删除尝试远端取消并丢弃迟到结果。
- 历史结果和当前已完成任务引用同一份真实输出；历史删除必须同步隐藏、撤销和正式移除任务行与统计。
- 生成图正式删除后按引用关系清理模板图与参考色内部关联，不得误删上传区素材。
- 彻底清空必须清除所有一键复色内部数据和文件。
- 不得把“只清界面记录”伪装成彻底清空。

### 27.6 系统错误熔断

需要统一分类全局错误与单任务错误。全局错误一次触发暂停闩锁；普通任务失败不得暂停整批。

## 33. 危险操作、模型重绑定与内部检查板边界

1. “彻底清空”使用危险操作专用弹窗：顶部明确不可恢复，中部同时展示“将被彻底清除”和“不会受到影响”，底部单独显示远端任务可能继续产生费用的风险。
2. 清空范围仍包括一键复色的上传素材、裁剪资料、任务、队列、生成图、历史结果、导出标记、缓存、临时文件和日志；画布内容、全局 API 设置和全局主题必须明确保留。
3. “原模型不可用”使用旧模型到新模型的关系图，分别显示失效状态、可用状态、可切换任务数量和保持原样的任务数量；系统不得自动替换模型。
4. 模型替换只影响尚未提交的任务，运行中请求、已完成结果、历史费用和等待远端确认的请求保持不变。
