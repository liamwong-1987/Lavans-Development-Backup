# Lavans 统一视觉系统 v1.1

状态：已整合冻结，负责全软件视觉令牌与组件规则

本文件是 Lavans 全软件视觉令牌与组件规则的权威来源。产品边界、页面例外和冲突裁决以 `LANVAS_UI_DECISION_REGISTER_V1.md` 为统一入口；效果图不得覆盖文字规则或真实功能。视觉修改必须同步更新受影响的文字规范和版本记录；效果图按决策总表的触发条件更新。

## 1. 设计定位

Design Read：这是面向高频创作用户的桌面生产工具保留式重设计。它需要高信息密度、稳定操作路径、高级设计师品牌感和克制的科技感。视觉系统采用 Lavans 自有设计令牌，交互密度和可访问性参考 Fluent 2，但不照搬微软外观。

- 模式：Redesign Preserve
- 视觉差异度：4/10。稳定网格为主，只在品牌按钮和选中状态创造识别度。
- 动效强度：3/10。只做悬停、按下、状态变化和主按钮流光。
- 信息密度：8/10。任务、缩略图、状态和诊断优先。
- 资产依赖：8/10。产品图片、真实界面和品牌标志必须使用真实素材。
- 品牌忠实度：10/10。功能、名称、描述、导航顺序和业务逻辑全部冻结。

## 2. 不可变产品边界

1. 只重新设计 UI，不改变功能、名称、描述、顺序、业务逻辑、数据边界和快捷操作。
2. 最左侧栏属于整个 Lavans，不属于一键复色。
3. 一键复色只占全局侧栏右侧的工作区。
4. 一键复色只删除自己的深浅主题按钮，主题由全软件统一控制。
5. 一键复色顶部“重置”保留。
6. 一键复色不增加独立 API 设置，读取全软件唯一 API 配置。
7. 浅色和深色使用相同 DOM、相同图标、相同文字、相同字号、相同尺寸和相同位置，仅替换主题令牌。
8. 软件品牌统一显示为 Lavans。除品牌名外，界面以中文为主。
9. 大雄致敬固定在全局侧栏底部，链接到 https://github.com/hero8152/Infinite-Canvas 。

## 7. 栅格和版面

本章数值用于复现已确认的 1920 px 视觉母版。一键复色内部可按已批准范围落地这些比例；全局外壳和其他生产页面继续沿用当前几何结构与响应式行为，不得仅为匹配母版数值而重构。

### 7.1 桌面母版

- 效果图尺寸：1920 x 1080 px。
- 全局顶栏：48 px 高。
- 全局左侧栏：232 px 宽。
- 应用内容外边距：16 px。
- 一键复色工作区圆角：24 px。
- 一键复色顶部状态栏：56 px 高。
- 一键复色内层工具栏：64 px 宽。
- 右侧预览与日志栏：340 px 宽，可折叠到 0。
- 中央工作区使用剩余宽度，常态占一键复色可用内容区约 74%。

### 7.2 一键复色纵向结构

1. 顶部状态栏：完成状态、全局主题由外壳控制、重置按钮。
2. 内容区：内层工具栏、中央主区、右侧检查栏。
3. 中央主区：统计摘要 92 px，上传与生成区 118 px，任务工具行 52 px，任务列表占剩余高度，底部批量操作 56 px。
4. 右栏：实时预览约 42%，系统日志约 58%。

### 7.3 任务列表

- 不使用传统翻页。
- 使用列表内部连续滚动和按需加载。
- 每行高度：116 px。
- 每行只显示模板图和生成图两张缩略图。
- 缩略图尺寸：136 x 78 px，圆角 10 px，object-fit cover。
- 两图之间放 18 px 箭头，不展示第三张参考色缩略图。
- 参考色在右栏和详情中查看。
- 列表字段顺序：选择、模板图、生成图、任务信息、状态、进度、问题诊断、操作。
- 每个任务都保留独立预览、下载、重做图标。
- 失败任务不另起一行，整行使用低透明红色底和左侧 2 px 红色状态线，问题诊断直接显示在同一行。

### 7.4 任务详情

- 打开缩略图后显示模板图、生成图、参考图三图横向对比。
- 三图顺序固定，不改变既有比较关系。
- 键盘左方向键查看上一任务，右方向键查看下一任务。
- 右上角关闭，底部保留当前任务重做。

## 8. 组件规则

### 8.1 圆角

- 应用工作区：24 px。
- 大面板和弹窗：16 px。
- 上传区和普通卡片：14 px。
- 输入框和按钮：10 px。
- 图片：10 px。
- 状态标签：999 px，只用于状态和短筛选项。

### 8.2 边框和阴影

- 普通分区优先使用 1 px 边框和留白，不给每段内容套卡片。
- 浅色面板阴影：0 12px 32px rgba(44,31,55,0.08)。
- 深色面板阴影：0 18px 42px rgba(0,0,0,0.28)。
- 浮层额外使用 1 px 内高光。
- 禁止纯黑硬阴影。

### 8.3 主按钮

- 高度：44 px。
- 最小宽度：148 px。
- 圆角：12 px。
- 背景：linear-gradient(110deg, #35105A 0%, #5E22A3 48%, #2A0847 100%)。
- 文字：#FFFFFF，14 px，600。
- 内边框：inset 0 1px 0 rgba(255,255,255,0.36)。
- 外阴影：0 8px 22px rgba(74,22,125,0.28)。
- 流光：宽度 36%，角度 18 度，从左到右 2.8 秒经过一次，间隔 4.2 秒。
- 流光颜色：rgba(231,214,255,0.70) 到透明。
- hover：亮度增加 6%，向上 1 px。
- active：scale 0.98。
- reduced-motion：关闭流光，只保留静态高光。
- 只用于每个区域唯一主操作，例如“检查设置并生成”。

### 8.4 次级按钮

- 高度：36 px。
- 圆角：10 px。
- 透明或 surface-2 背景，1 px 边框。
- hover 只改变背景和边框，不发光。

### 8.5 危险操作

- 重置、删除、清空日志、清理任务、彻底清空缓存不得使用主按钮视觉。
- 普通状态使用中性按钮。
- 确认弹窗内才使用红色确认按钮。
- 必须说明影响范围并要求二次确认。

### 8.6 输入与上传

- 上传模板和参考色区域始终保留。
- 上传区采用明确边框，不使用过大的虚线框。
- 标题、数量、支持格式和上传按钮同一区域内完成。
- 拖入时边框切换 brand-500，背景切换 brand-100 或深色对应透明紫。
- 不使用 placeholder 代替字段标题。

## 9. 动效规则

- 页面和区域切换：180 ms，cubic-bezier(0.16,1,0.3,1)。
- hover：140 ms。
- 弹窗进入：220 ms，opacity 加 translateY 8 px。
- 右栏折叠：240 ms，宽度与透明度同步。
- 状态变化：180 ms，只改变颜色、图标和短文字。
- 列表加载使用与最终行相同形状的骨架，不使用通用圆形转圈。
- 除主按钮流光外，不使用永久循环动画。
- 所有动效尊重 prefers-reduced-motion。

## 10. 全软件应用规则

### 10.1 软件外壳

- 全部页面共用同一个全局左侧栏、品牌区、主题状态和基础令牌。
- 全局导航名称、顺序、描述和路由不变。
- 选中项使用 brand-100 或深色透明紫底，图标和文字使用品牌紫。
- 非选中项不使用状态圆点。

### 10.2 普通画布与无限画布

- 不改节点类型、工具位置、资产逻辑和画布交互。
- 画布背景保持适合内容观察的中性颜色。
- 工具条、节点外壳、弹窗、提示和状态灯使用本规范令牌。
- 深浅模式仅换色，不移动节点、工具条和侧栏。

### 10.3 画布 Agent

- 对话、Skill 卡片、设置、审核卡片、状态灯和中断按钮使用本规范组件。
- 所有中文文案和现有交互不改。
- 主执行按钮可使用紫色流光玻璃。
- 审核失败必须在原步骤清楚显示原因和重做入口。

### 10.4 API 设置

- 保留全软件唯一 API 设置入口。
- 表单标签置于输入框上方。
- 站点、模型、比例、质量和密钥状态使用统一输入和状态组件。
- 不在一键复色内复制 API 设置界面。

### 10.5 素材库和其他工具

- 图片卡片、列表、搜索、筛选、上传、弹窗和空状态全部使用同一字体、颜色、圆角和图标系统。

### 10.6 视频系统

- 视频模型设置、画布视频节点、Agent 逐镜视频工作台、最终合成与交付全部继承本规范，不建立独立品牌、主题、字体或图标体系。
- 视频主操作继续使用 Lavans 深紫流光玻璃按钮；橙色只表达排队、等待和警告，不作为视频品牌色。
- 视频失败保留原提示词、素材、成功镜头和历史版本；中转站故障允许重试，内容安全失败进入提示词联动修改和单镜头重做。
- 剧本、分镜、声音、逐镜视频和最终成片必须保留人工审核，不提供跳过审核的一键成片。
- 详细页面结构、状态和图标映射以 `LANVAS_PAGE_UI_SPEC_V1.md` 为准。
- 不改变各系统的素材边界和数据来源。

## 11. 响应式规则

- 各生产页面保留现有断点、折叠、抽屉、滚动和栏宽行为；视觉系统只保证主题与组件在这些状态下清晰一致。
- 在 1440 px、1280 px 和较窄窗口中验证文字、图标、按钮、弹窗和主要操作不重叠、不裁切。
- 若需要新增或改变响应式结构，视为版面改造，必须暂停并取得用户批准；一键复色只在已批准内部范围内例外。
- 所有缩放都不得改变功能名称、顺序或深浅主题结构，也不得用压缩中文字体解决空间问题。

## 12. 可访问性和状态覆盖

- 正文对比度至少 4.5:1。
- 18 px 以上大字至少 3:1。
- 焦点环使用 2 px brand-500，外偏移 2 px。
- 键盘顺序与视觉顺序一致。
- 状态必须有颜色、图标和文字三者中的至少两种。
- 必须设计默认、hover、focus、active、disabled、loading、empty、error、success 状态。

## 13. 版本同步规则

每次设计修改必须完成以下三项；效果图按需更新：

1. 修改本文件并升级版本号。
2. 更新受影响的页面规范或决策记录。
3. 在变更记录中写明改动原因和影响组件。

用户要求效果图或出现重大视觉分歧时，重新导出受影响页面的浅色与深色效果图；两种主题除颜色、材质、阴影和可读性状态外必须同构。日常实现以真实软件浏览器截图和交互测试作为主要验收证据。禁止只改效果图而不更新文字规范。
