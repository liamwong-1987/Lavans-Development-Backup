# Lavans 全软件页面级 UI 规范 v1.1

状态：已冻结，供效果图、产品实现和验收共同使用。  
视觉令牌规范：`LANVAS_DESIGN_SYSTEM_V1.md`。统一决策入口：`LANVAS_UI_DECISION_REGISTER_V1.md`。  
本文件定义跨页面视觉一致性和现有页面换肤规则，不修改功能、名称、描述、路由、数据边界或业务逻辑；除第 12 章列明的一键复色已批准范围外，不修改现有版面位置。

## 1. 统一原则

1. 全软件只存在一套 Lavans 视觉系统。软件外壳、本地工具、GPT 对话、项目列表、普通画布、无限画布、画布 Agent、素材库、一键复色、API 设置、工作流设置和视频系统全部继承同一套令牌。
2. 中文界面统一使用 `MiSans VF`；回退为 `PingFang SC`、`Microsoft YaHei UI`、`sans-serif`。日志、代码、任务编号只使用 `JetBrains Mono`。
3. 图标统一使用 `Phosphor Icons Duotone`。同一动作在所有页面使用同一图标、同一名称和同一语义，不允许 Lucide、手绘 SVG、Emoji 和不同图标家族混用。
4. 品牌色为深紫。主操作使用“紫色光带玻璃”按钮；绿色、琥珀色、红色只表达完成、等待/警告、失败/危险状态。
5. 深色与浅色共用同一组件、DOM、中文文字、图标、字号、尺寸、列宽和位置，只替换颜色、边框、阴影、材质与对比度令牌。
6. 不新增或删除功能，不修改已有功能名称和描述，不改变导航顺序，不改变素材、任务、项目、Provider 和模型的数据边界。
7. 全局左侧栏属于整个 Lavans。页面内部不得复制全局导航、主题按钮或全局 API 设置入口。
8. 每个区域最多一个主按钮。次级操作使用中性按钮；危险操作进入二级菜单并二次确认。
9. 高信息密度依靠稳定栅格、折叠栏和弹窗解决，不允许通过缩小字体或压窄字体腾空间。
10. 默认采用“零版面重构”的保留式 UI 改造：当前生产页面的区域位置、宽高比例、左右/上下关系、列宽、按钮位置、弹窗位置、滚动方式、折叠方式、响应式断点和交互路径全部冻结。
11. 第 12 章的一键复色是唯一已批准例外：保留全局导航和内层左中右大结构，允许按已确认效果调整复色工作区内部尺寸、留白、行高、缩略图、工具栏、统计区和右侧面板比例。
12. 除该例外外，本文件后续章节对页面区域的说明只用于识别现有功能，不构成重新排版指令；如文字说明与当前生产页面几何结构不一致，始终以当前生产代码和真实截图为准。允许改变的是字体与字重体系、同尺寸图标替换、主题颜色、边框、圆角、阴影、磨砂材质、焦点环和组件状态。

## 5. 本地生成工具页面

文生图、细节增强、图片编辑、角度控制和在线生图共用视觉令牌与组件，各自现有生产版面原样保留。

### 5.1 只统一视觉，不调整骨架

- 页头沿用当前生产高度与内容位置；统一页面名、原有描述和连接状态的视觉层级，不增加第二个品牌栏。
- 统一上传、表单、选择卡、结果卡、历史抽屉、状态和按钮组件。
- 历史记录、设置栏、结果区、上传区和操作栏的位置完全沿用当前页面，不新增抽屉、不改变栏数。
- 禁止为了视觉统一强迫页面采用左中右、上下或任何新的结构，也禁止把原结构改成另一种结构。
- 主按钮只替换视觉皮肤，不移动位置、不改变尺寸、不合并现有入口。

### 5.2 文生图

- 保留“统一创作控制台”、引擎来源、本地/ModelScope、尺寸、本地生成、历史记录、结果尺寸、提示词预览和复用。
- 现有主按钮使用紫色光带玻璃皮肤；模型、尺寸和其他控件保留当前生产形态、名称、尺寸与位置。
- 结果网格支持预览、下载、复制提示词和复用；图标遵循统一词典。

### 5.3 细节增强

- 原图上传、细节增强强度、超分倍率及“原图｜增强结果”的现有位置全部保留。
- 主按钮保留“开始重绘”；生成中显示阶段、百分比、已用时间和可取消状态。
- 历史结果沿用当前呈现方式；保留保存能力，不修改算法、参数含义或位置。

### 5.4 图片编辑

- 主图、参考图 A、参考图 B、提示词、引擎、LoRA、强度和结果画布的现有位置全部保留。
- 不改变参考图数量、标签、切换方式或现有栏数。
- 保留执行合成、状态、历史、提示词预览和复用。

### 5.5 角度控制

- 原图、水平旋转、俯仰、距离、提示词、引擎、相机方向示意、结果预览和历史的现有位置全部保留。
- 参数改变只更新相机示意，不伪造生成结果。
- 保留生成新角度、进度、历史和保存。

### 5.6 在线生图

- 提示词、主参考图、参考图 A/B、模型、质量、数量、尺寸、比例和结果网格的当前版面位置全部保留。
- 质量、数量和比例采用可勾选卡；自定义尺寸只在选中“自定义”后展开输入。
- 主按钮、状态和费用信息不移动，只做 Lavans 视觉换肤。

## 6. GPT 对话

- 会话栏、系统提示词、消息流、输入框、附件、引用、模型和尺寸的当前区域、宽度、位置和开合方式全部保留。
- 中文界面统一换用 MiSans 字体体系；代码和任务编号使用 JetBrains Mono，但不得因字体替换改变布局宽高。
- 输入框只替换磨砂材质、边框、圆角和状态，不重排内部按钮。
- 模型选择读取唯一 API 设置，不复制平台管理。
- 清除和删除属于危险操作，必须二次确认；保存系统提示词保留原功能。
- 流式、思考中、失败、停止、重试、复制和重新生成均使用统一状态与图标。

## 7. 项目与画布列表

- 项目、默认项目、回收站、粘贴目标、画布卡片区和新建入口的当前版面及位置全部保留。
- 画布卡片区保留当前平移、缩放、重置、拖动、打开和菜单行为。
- “新建画布”保留当前位置和智能画布/普通画布选择，只换视觉皮肤。
- 卡片更多菜单保留重命名、移动、剪切、粘贴、删除和导出 JSON/ZIP/资源。
- 回收站保留恢复和永久删除；永久删除使用红色确认按钮且明确不可恢复。

## 8. 普通画布与智能画布

### 8.1 共同结构

- 画布是唯一主工作区，禁止用大型卡片遮挡。
- 顶部浮动栏、节点工具栏、底部画布工具栏和右侧检查栏的当前位置、尺寸、开合方式和内容顺序全部保留。
- 图标替换必须使用与当前图标相同的包围盒和点击区域，避免工具条位移。
- 节点状态灯固定为等待、运行、待确认、完成、阻塞、失败、暂停、取消；状态有颜色和中文文字双重表达。

### 8.2 普通画布

- 保留图片、提示词、循环、LLM、API 生成、ModelScope、视频、MiniMax、RunningHub、ComfyUI、LTX Director、输出和分组节点。
- 保留工作流与素材库、日志、拖入上传、自动排列、导入导出、提示词模板及完整图片编辑功能。
- 节点标题可继续显示现有技术名称；节点操作统一使用图标词典。

### 8.3 智能画布

- 保留图片、音频、视频上传和所有智能节点能力。
- 模型/比例/时长等高频设置在节点检查栏呈现；全局平台和密钥仍只由 API 设置管理。
- 视频节点必须使用本规范，不建立独立橙色视觉语言。

## 9. 画布 Agent

### 9.1 入口与 Skill 选择

- Agent 入口保留在智能画布；打开后先显示 Skill 卡片库，再进入选定 Skill 的对话与执行页。
- 当前只有一个 Skill 时仍显示一张卡片，预留未来多 Skill，不把 Skill 内容写死为“皮克斯”。
- Skill 卡使用统一面板；名称、能力摘要、资料需求、预计阶段和进入按钮清晰可见。

### 9.2 对话与资料提交

- Agent 栏沿用当前宽度、位置与折叠行为；消息只替换字体体系和颜色令牌。
- 能勾选的问题必须使用单选或多选卡，默认不要求打字；只有“其他”展开文本输入。
- 选项文字放大时卡片同步增高，说明自然换行，不裁切。
- 输入区支持图片、文档、Markdown 和压缩包；显示真实文件名、类型、大小、解析状态和移除操作。
- 资料、对话、画布节点和已锁定产物保持明确引用关系。

### 9.3 可见执行链

- 用户启动后，系统必须先在画布创建可见阶段节点，再开始真实执行。
- 节点按 10 阶段从左到右生长；阶段内部产物向下展开；连线显示依赖与过期传播。
- 每个节点展示状态灯、阶段名、版本、输入摘要、费用状态和唯一主动作。
- 全局支持暂停、继续和取消；取消保留已完成节点与产物；失败只影响失败阶段或镜头。

### 9.4 审核规则

- 不提供“一键成片”。一句话只启动工作流。
- 创意、完整剧本、结构化分镜、资产台账、视觉资产、故事板、声音方案、逐镜视频和最终交付均保留人工审核。
- 每个阶段的集中审核只提交一次；后台完成批准和锁定，不让用户重复点击。
- 上游改变时保留下游成果并标记“需要复核”或“已过期”，由用户决定重做范围。

## 10. Lavans 视频系统

视频系统不是单独品牌，也不是独立皮肤。它由“视频模型设置、画布视频节点、Agent 逐镜视频工作台、最终合成与交付”四部分组成，全部严格继承 Lavans 统一规范。

### 10.1 视频模型设置

- API 站点、密钥、协议和模型只在全局 `API 设置` 管理。
- 视频模型卡与图片模型、聊天模型使用相同卡片结构；类型以中文标签“视频”表达，不使用整块橙色。
- 卡片显示平台、模型名、可用状态、支持比例、时长、分辨率、价格/计费提示和验证结果。
- 选择、验证、保存、删除、拉取模型全部使用统一文字和图标。

### 10.2 视频生成节点

- 节点头部：视频图标、节点名、状态灯和更多菜单。
- 节点主体：首帧/尾帧或参考素材、提示词摘要、Provider、模型、比例、时长和分辨率。
- 节点底部：预计费用、版本和进度；运行中显示百分比、已用时间和暂停/取消。
- 成功后显示视频缩略图、播放、下载、重做和版本入口。
- 失败后不清空原提示词和已上传素材；显示失败类型、可恢复性和唯一建议动作。

### 10.3 逐镜视频工作台

- 镜头目录、播放器、版本区和审核栏沿用当前生产页面的位置、尺寸、栏数和折叠方式；在智能画布中继续沿用现有 Agent 审核栏。
- 镜头目录显示镜头编号、状态、时长和缩略图；失败只标红对应镜头。
- 中间固定显示锁定首帧、锁定尾帧、当前视频和历史版本；禁止把所有镜头自动合成为成片。
- 右栏显示提示词、模型、比例、时长、分辨率、费用、问题诊断和审核清单。
- 每个镜头独立生成、独立预览、独立选择和独立重做；全部镜头最后只提交一次阶段审核。

### 10.4 失败、违规与提示词联动

- 中转站、网络、超时和服务端错误：保留原提示词，提供“重试当前镜头”和备用模型选项。
- 内容安全或违规：进入勾选式问题选择，展示原词、建议新词和修改原因；用户确认后生成新提示词版本。
- 提示词修改只影响当前镜头，旧版本永久保留；新一轮付费调用前必须再次显示费用并勾选确认。
- 质检失败：问题诊断与提示词修改联动，允许局部重做，不删除已经通过的镜头。

### 10.5 合成、质检与交付

- 只接受已锁定且完整的阶段 8 声音包和阶段 9 视频包；缺任一镜头时主按钮禁用并显示缺失原因。
- 合成页三栏：输入清单、合成进度/播放器、质检与交付。
- 自动质检和人工清单使用同一审核组件；7 项清单全部通过后仅需一次“提交审核”。
- 交付区固定显示 MP4、SRT、质检报告、版本来源说明和 ZIP；每项有下载、校验状态和文件大小。
- 受控测试素材必须以琥珀状态条明确标记“不是正式品牌成片”。

### 10.6 视频主题与图标

- 视频主操作仍使用 Lavans 深紫流光玻璃按钮。
- 视频播放使用 `PlayCircle`，暂停使用 `PauseCircle`，逐镜列表使用 `FilmStrip`，合成使用 `VideoCamera`，字幕使用 `Subtitles`，声音使用 `Waveform`，质检使用 `SealCheck`。
- 琥珀色只用于排队、等待确认和警告；红色只用于失败、违规和危险确认；绿色只用于完成和通过。
- 深浅模式仅替换令牌，视频缩略图、播放器比例、图标、中文文字和操作位置完全一致。

## 15. 组件状态覆盖

每个页面和组件必须覆盖：默认、悬停、按下、聚焦、选中、禁用、加载、空状态、成功、等待、警告、失败、暂停、取消、离线和无权限。

- 焦点环：2 px `brand-500`，外偏移 2 px。
- 点击目标：图标按钮最小 36×36 px；主要触控目标 44×44 px。
- 状态不得只依靠颜色，至少同时提供中文文字或图标。
- 深色正文达到可读对比，不允许灰字沉入背景。

## 16. 响应式优先级

- 保留各生产页面当前已有的断点、折叠、抽屉、滚动和栏宽行为，不新建统一响应式骨架。
- 在 1440 px、1280 px 和较窄窗口中验证视觉皮肤不会造成文字裁切、重叠、横向溢出或操作丢失。
- 若现有窄窗口行为本身存在缺陷，先记录为独立问题；修复会改变结构或交互路径时必须暂停并取得用户批准。
- 任何窗口尺寸都不得通过缩小或压窄中文字体解决空间问题。

## 17. 效果图与实现同步

页面效果图必须使用真实名称、真实功能和真实顺序。规范和实现按以下方式同步：
