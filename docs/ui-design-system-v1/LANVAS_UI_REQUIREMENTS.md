# Lavans 全软件 UI 改造：需求与边界

统一执行入口：`LANVAS_UI_DECISION_REGISTER_V1.md`。如历史效果图、页面规范或实现描述存在差异，以该决策总表和本文件的产品边界为准。

状态：阶段一已建立，后续阶段以本文件和页面级规范共同作为恢复依据。

## 目标

在不改变 Lavans 任何既有功能、名称、描述、路由、数据归属和操作路径的前提下，建立统一的高质感视觉系统，并将一键复色按已确认效果图精确还原。

## 已确认决定

- 品牌名统一为 `Lavans`；不再把 Lavans 作为可见产品品牌。
- 品牌主色为深紫；主要操作使用带斜向光带、玻璃高光和轻微辉光的紫色按钮。
- 深色与浅色使用相同的页面结构、中文文字、图标、字号、尺寸和操作位置，只替换主题令牌与材质。
- 中文正文使用 MiSans VF；日志、代码与任务编号使用 JetBrains Mono；图标使用 Phosphor Duotone 语义体系。
- 全局左侧栏是整个软件唯一导航。名称、顺序、入口和折叠行为均保持不变。
- 左侧栏底部固定“改自大雄画布，致敬原作”，并链接至 https://github.com/hero8152/Infinite-Canvas 。
- API 设置继续是唯一 API 配置来源；其版块、字段、顺序、位置和功能不可重构。
- 一键复色与画布系统互不共享素材、模板、任务、项目或生成记录。

## 一键复色特殊验收

- 保留全局导航及内层左中右大结构，允许调整复色工作区内部的尺寸、留白、行高、缩略图、工具栏和右侧面板比例，以匹配已确认效果图。
- 任务列表只显示“模板图 → 生成图”；参考色仍在右栏与三图详情内。
- 保留模板图与参考色上传、自动配对、筛选、批量操作、生成、重置、日志、失败诊断、预览、下载、单任务重做与删除。
- 不分页；连续滚动。失败原因必须在同一行显示。
- 复色内部不再提供独立深浅模式按钮；主题由软件全局入口统一控制。

## 禁止事项

- 不删除、改名、合并或替换已有产品功能、描述、API、路由、数据表或业务逻辑。
- 不让画布、一键复色、素材库或 API 配置产生新的数据互通。
- 不重排 API 设置；其他页面也默认仅做视觉换肤，除非用户明确批准该页面的内部布局调整。
- 不重置、清理、覆盖、暂存、提交、推送当前工作区已有修改。

## 验收方式

每个阶段完成后先由 AI 进行静态检查、真实浏览器操作与适用的自动化测试；修复本阶段问题后暂停，等待用户审核。
