## 一、任务背景

复色模块「一键生成」要彻底打通画布 Provider。目标体验：生成前用户能像画布 API 生成节点一样，选定 **Provider / 模型 / 尺寸 / 质量 / 数量** 五个参数，而不是只点一个裸按钮。

接手时的状态是半成品：
- 后端 Provider 路由已通（`apiClient.js` 的 `resolveProvider`/`providerConfig`）。
- 前端弹窗只做了 2 项（Provider + 质量），缺模型/尺寸/数量。
- 前后端 `model` 参数**未贯通**——前端选了 Provider 但实际生图仍走默认第一个模型。

## 二、断点判断（接手时定位）

| 层 | 文件 | 接手时状态 |
|----|------|-----------|
| 后端 Provider 路由 | `apiClient.js` | 已通 |

| 后端接口+批次 | `server.js` | 只接收 providerId/quality，缺 model/quantity |

## 三、修改内容（5 个文件，+104/-26）

### 1. `resources/frontend/app.js`
- 全局变量：新增 `recolorModel`（默认空）、`recolorSize`（默认 1024x1024）、`recolorQuantity`（默认 0=全部），删除写死的 `RECOLOR_SIZE`。
- `openGenerateDialog()`：弹窗补全为 5 项——Provider（保留）、模型下拉（按当前 Provider 的 `image_models` 动态生成）、尺寸下拉（1024/1536/2048 三档）、质量（保留）、数量输入（默认=本次配对数，0/空=全部）。
- Provider 下拉绑 `onchange` 联动刷新模型下拉。
- `confirmGenDialog()`：读取 5 项写入全局变量 + localStorage（`recolor_provider`/`recolor_model`/`recolor_size`/`recolor_quality`/`recolor_quantity`）。
- 页面初始化从 localStorage 恢复 5 项（size/quality 硬枚举兜底，quantity parseInt 兜底）。
- 3 处 `generate-v2` 请求体（追加/新建/继续）统一加 `model`/`quantity`，`size` 改动态。
- 文案更新为「Provider / 模型 / 尺寸 / 质量 / 数量」。

### 2. `resources/backend/server.js`
- `/api/generate-v2` 新增接收 `model`、`quantity`；`size` 加 trim 兜底。
- 追加路径给 `latest.model` 赋值；`prepareBatch` 签名加 `model` 并透传 `createBatch`。
- 数量截断：去重后、追加/新建前各插入 `if (quantity>0 && quantity<pairs.length) pairs=pairs.slice(0,quantity)`，覆盖两条路径。

### 3. `resources/backend/batchStore.js`
- `createBatch` 批次对象新增 `model: options.model || ''`。

### 4. `resources/backend/services/taskService.js`
- 调 `apiClient.editImage` 透传 `model: task.model || batch.model || ''`。

### 5. `resources/backend/apiClient.js`
- `editImageOnce`/`editImageWithApimart`/`editImageWithGemini` 均支持 `model` 入参，用 `model || pcfg.imageModel` 覆盖默认第一个模型，三条协议路径（openai/apimart/gemini）均生效。

## 六、备注（非阻塞，供参考）

1. **model 脏值兜底**：provider/model 属动态字段，init 无法静态枚举校验，仅 `|| ''` 恢复。若 model 是过期值，下次打开弹窗因无匹配 option 自动落首个模型；空 model 由 apiClient 兜底，不会报错。
2. **切换 Provider 观感**：`genProviderChanged` 重建选项时 `selected` 短暂反映旧值（纯 UI 观感），浏览器自动选首项兜底，不影响功能。
