# 复色画布复刻补全 — promptGroup 节点 + 提示词模板库 实施报告

- 日期：2026-08-17
- 范围：`resources/frontend/canvasStudio.js` + `resources/backend/routes/canvasRoutes.js` + `resources/frontend/style.css` + 新增 `resources/backend/system-prompts/`

## 一、背景

用户要求"继续画布复刻，把全部复刻完"。经系统对比大神画布（canvas.js），复色画布（canvasStudio.js）有两个明确缺口：

1. **promptGroup 节点**（提示词组）—— 唯一缺失的节点类型
2. **提示词模板库** —— Composer 的「模板库」按钮是假的（硬编码填一句提示词），大神有完整的模板弹窗系统

## 二、promptGroup 节点复刻（提交 859055a）

| 项 | 内容 |
|----|------|
| 辅助函数 | `canvasIsGroupNode(type)`，把约 30 处 `type === 'group'` 判断点扩展为同时识别 group + promptGroup |
| 端口 | 输出 `prompt` 类型（输出合并提示词文本），无输入端口 |
| body | 显示「包含 N 个提示词」，复用 group 的操作按钮 |
| 创建菜单 | 新增「提示词组」卡片 |

QA 验证 9/9 PASS。

## 四、QA 发现并修复的两个 bug

### Bug A（阻断级）：内置模板被持久化文件绕过
- **现象**：现有 `prompt-libraries.json`（system.items=0）存在时，注入的内置模板不生效，弹窗为空。
- **修复**：`normalizePromptLibraryStore` 对 system 库无条件合并内置模板（过滤已存在的 id）。
- **验证**：持久化文件存在时合并后 system.items = 10 个内置模板 ✅

### Bug B（轻微）：末个预设 params 丢失
- **现象**：`extractPromptTemplateSection` 正则只止于 `###`，预设10 的「平台参数建议」吞入后续「## 通用负面词库」，导致 params 为空。
- **修复**：正则 lookahead 扩为 `(?=\n#{2,3}\s+|\s*$)`，同时止于 `##` 和 `###`。
- **验证**：10 个模板 params 都有 3 个值 ✅
