# 复色画布 8 经典节点补端口连线 — 实施报告

- 日期：2026-08-17
- 范围：`resources/frontend/canvasStudio.js` 单文件
- 结论：IS_PASS: YES（QA 8/8）

## 一、背景与断点

复色画布（canvasStudio.js）已迁移 8 个经典节点（llm / midjourney / msgen / video / rh / comfy / ltxDirector / output），body 渲染、defaults、尺寸、字段编辑均已齐备。但 `canvasPortType()` 不认这 8 个类型，导致它们**无输入/输出端口、无法连线，是"孤岛节点"**。

本次补上端口，让它们按语义参与连线，**不接真实 API**（运行态维持"未接入"）。

## 二、端口映射（对齐大神 canConnect 语义的精简版）

| 节点 | 输入端口（左） | 输出端口（右） |
|------|--------------|--------------|
| llm | prompt ×1 | prompt ×1 |
| midjourney | prompt ×1, asset ×1 | image ×1 |
| msgen | prompt ×1, asset ×1 | image ×1 |
| video | prompt ×1, asset ×1 | image ×1 |
| rh | prompt ×1, asset ×1 | image ×1 |
| comfy | prompt ×1, asset ×1 | image ×1 |
| ltxDirector | prompt ×1 | image ×1 |
| output | image ×1 | 无（终端） |

端口类型沿用现有 4 种（asset / prompt / image / flow），未引入新类型。

## 三、改动（3 个函数）

| 函数 | 改动 |
|------|------|
| `canvasPortType` | 补 8 节点的 out/in 端口类型映射 |
| `canvasNodePorts` | 补 8 节点的端口 HTML 渲染 |
| `canvasPortPosition` | 输出端口 x 改用节点实际宽度；补多输入端口 y 偏移 |

未改动：`canvasPortAllowed`（端口类型匹配逻辑复用）、`canvasConnectionAllowed`、`canvasPortLabel` 及核心闭环相关代码。

## 四、连线语义（验证通过）

- 正向可连：prompt→llm、llm→midjourney、image→midjourney（asset→asset）、midjourney→output（image→image）、llm→llm
- 反向阻断：output→prompt、midjourney→prompt（image 输出 vs prompt 输入，类型不匹配）
