# PROMPT 放大 @ 图功能修复（终态 · 已验证通过）

**日期**: 2026-08-18（修复落地）  
**验证通过**: 2026-08-19 用户实测确认

**文件**: `resources/frontend/smart-canvas-core/smart-canvas-core.js`

## 问题

智能画布中，放大 PROMPT 提示词框后，输入 `@` 符号能输入，但不会弹出参考图选择器（mention-picker），无法把参考图作为 @ 引用插入 PROMPT。

## 根因（两层）

### 第一层：@ 提及 HTML 在纯文本路径丢失
`node.text` 由 textarea `oninput` 写入纯文本（`e.target.value`），而真正的 @ 提及 HTML 存在 `node.promptDraftHtml`。放大框最初用 `control.value`（纯文本）同步，@ 提及 span 被丢弃。

### 第二层（真正导致"@ 不弹选择器"）
放大框 `#promptExpandInput` 自始至终没有绑定提及相关监听；且 `saveMentionRange()` / `textBeforeCaret()` 硬编码 `#promptInput`，在放大模式下 `window.getSelection()` 的锚点落在 `promptExpandInput` 上，工具函数却去 `promptInput` 里找 Range，结果为空 → `maybeOpenMentionPicker` 无法打开。页面外点击关闭白名单也未包含放大框。

## 修复

### 1. 同步源改用 HTML 优先级链（保留 @ 提及）
`handleSmartPromptExpandPointer` 与 `expandSmartPromptEditor` 均改为：
```js
const rawHtml = node?.promptDraftHtml || node?.text
    || (control.value ?? control.innerText ?? '').replace(/\n/g, '<br>');
promptExpandInput.innerHTML = rawHtml;
```
5 个调用方统一传入 `node` 参数。

### 2. 新增活动编辑器识别
```js
function isComposerExpanded(){
    return !!promptExpandModal && !promptExpandModal.hidden && !smartPromptExpandTarget;
}
function activePromptEditor(){
    return isComposerExpanded() ? promptExpandInput : promptInput;
}
```

### 3. 工具函数改用活动编辑器
`saveMentionRange()`、`textBeforeCaret()` 第一行改为 `const editor = activePromptEditor();`，不再硬编码 `#promptInput`。

### 4. 放大框绑定全套提及监听
```js
if(promptExpandInput){
    promptExpandInput.addEventListener('input', () => { maybeOpenMentionPicker(); /* 同步回 promptInput 或 target */ });
    promptExpandInput.addEventListener('keydown', e => {
        if(e.key === 'Escape') collapseComposerPrompt();
        if(e.key === '@') requestAnimationFrame(maybeOpenMentionPicker);
    });
    promptExpandInput.addEventListener('keyup', maybeOpenMentionPicker);
    promptExpandInput.addEventListener('mouseup', saveMentionRange);
    promptExpandInput.addEventListener('focus', saveMentionRange);
}
```

### 5. 关闭白名单放行放大框
```js
// 页面外点击关闭逻辑
if(!event.target.closest('.mention-picker')
   && !event.target.closest('#promptInput')
   && !event.target.closest('#promptExpandInput')   // 新增
   && !event.target.closest('[data-input-add-reference]')) closeMentionPicker();
```

### 6. 防御性兜底
`savePromptDraftForCurrent()` 在每次 composer 输入时保存 `promptDraftHtml`（HTML）与 `promptDraftText`（纯文本），优先级链确保即使缓存被复刻清空也不崩溃。
