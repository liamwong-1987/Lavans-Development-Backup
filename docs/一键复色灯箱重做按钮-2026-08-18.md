# 一键复色灯箱重做按钮

**日期**: 2026-08-18  
**文件**: `resources/frontend/app.js`（单文件）  
**分支**: 一键复色（recolor），不涉及智能画布

---

## 需求

在灯箱（放大生成图后显示的三图预览）底部加"重做"按钮。用户发现某个任务生成结果不合格，立刻可以重做。

## 改动清单

### 1. HTML 结构（布局修正）

**问题**：原 `rv-retry` 和 `rv-container` 是 `.img-viewer-body`（flex row）的直接兄弟节点，导致重做按钮被挤在图片右侧而非底部。

**修复**：新增 `rv-wrapper`（flex column），包裹 `rv-container` + `rv-retry`：

```
rv-wrapper (flex column, height:100%)
├── rv-container (flex:1, 图片区)
└── rv-retry (flex-shrink:0, 重做按钮条)
```

- `rv-container` 从 `height:100%` 改为 `flex:1;min-height:0`
- `rv-retry` 加 `flex-shrink:0;padding:12px 0 6px`

### 2. show/hide 切换

| 函数 | 原来 | 改成 |
|------|------|------|
| `openImagePreview` | `rv-container` → none | `rv-wrapper` → none |
| `openImageRowPreview` | `rv-container` → block | `rv-wrapper` → flex |
| `closeImagePreview` | 仅隐藏 `rv-retry` | 隐藏 `rv-retry` + `rv-wrapper` → none |

### 3. 重做按钮显隐逻辑（`loadRowPreview`）

```js
var canRetry = !!task && isCompletedTask(task) && !!getSrc(2);
```

- 使用统一 `isCompletedTask()` 判断（覆盖 completed/success/done/finished）
- 同时检查输出图是否存在

### 4. 重做执行（`clickRvRetry`）

```js
var ok = await retrySingleTask(bid, tid, true, false);
```

- `skipConfirm=true`（灯箱内不弹确认框）
- 点击后按钮变 "重做中…"，状态显示 "排队中…"
- 失败显示 "重试" / "失败，请重试"

**关键修复**：`retrySingleTask` 内部 `refreshAndRender` 会重建 DOM，导致 `__rvRows` 里的旧节点失效。重做成功后重新扫描 `__rvRows` 并通过 `dataset.task` 定位到同一任务行。

### 5. 对比面板重做按钮（附带修复）

原 `canRetry` 只检查 `es === 'completed'`，改为与灯箱一致的 `isCompletedTask(task)` 判断。
