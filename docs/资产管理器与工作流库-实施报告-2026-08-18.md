## 实现内容

### 1. 资产管理器（asset-manager-modal）

入口：资产库面板头部「管理」按钮。

| tab | 功能 |
|------|------|
| 图片资产 | 库列表 + 分组列表 + 新建/重命名/删除库 + 新建/重命名/删除分组 + 添加URL + 批量上传 + 批量删除 + 卡片重命名/删除 |
| 工作流 | 工作流分组 + 新建分组 + 上传工作流（JSON/ZIP）+ 批量删除 + 卡片重命名/删除 |

复用后端已有的 `/api/canvas/assets-library/*` 完整 CRUD 接口（库/分组/项的新建/重命名/删除/批量）。

### 2. 工作流导出到库

入口：工作流弹窗新增「导出到库」按钮。

- 把选中节点的工作流 JSON 序列化成 Blob，通过 `/api/canvas/assets-library/workflows/upload` 上传到工作流分组
- 可在资产管理器「工作流」tab 中查看、重命名、删除、重新导入

## 关键技术点

- 新增 `canvasAssetApi(url, method, body)` 辅助函数支持 GET/POST/PATCH/DELETE（原 `api()` 只支持 GET/POST）
- 批量上传复用 `uploadCanvasCroppedBlob`（先传 local-assets 再入资产库）
- 复用现有 `canvasAssetLibrary` 数据 + `renderCanvasAssetLibrary` 渲染
