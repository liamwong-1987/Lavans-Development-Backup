# Canvas Agent 续作交接（2026-08-21）

## 一、当前结论

Canvas Agent 的新版 10 阶段功能路线已经完成到阶段 10 的开发和受控测试，但正式品牌成片尚未交付。

- 阶段 1–8：已开发、已测试、已由用户验收。
- 阶段 9：已开发并通过自动化与软件内浏览器测试，等待用户验收。
- 阶段 10：已开发并通过隔离受控合成测试，等待用户验收。
- 正式品牌路径：仍停在阶段 9.3。镜头 2 被内容安全策略拦截，必须先完成该镜头的提示词联动修改、费用确认、局部重做和人工验收，才允许锁定完整逐镜视频包。
- 阶段 10 的受控测试产物只用于验证合成、字幕、声音、质检、打包和恢复链路，不能作为正式品牌成片交付。

当前唯一下一步不是重新开发阶段 1–8，也不是绕过失败镜头直接合成，而是恢复阶段 9.3 的镜头 2。

## 二、已经具备的能力

1. 多 Skill 卡片入口、资料上传、勾选式问询和画布可见执行节点。
2. 节点状态灯、暂停、继续、取消、失败隔离、刷新恢复和新窗口恢复。
3. 产品事实与调研边界、创意方向、纯文字剧本、不可变版本、差异对比和一次提交锁定。
4. 结构化分镜、角色/产品/场景/道具/Logo 资产台账与覆盖校验。
5. 图片和视频 Provider、模型、比例、数量、模式、预算、备用模型和重试策略；配置读取全局画布 API 设置。
6. 视觉资产生成与选择、产品实拍图强绑定、逐镜首尾帧、故事板和本地调度图。
7. 旁白、对白、字幕、音乐、音效和逐镜纯文字视频提示词制作包。
8. 每个镜头独立生成、播放、选择、失败、重做和版本保留；一个镜头失败不影响其他成功镜头。
9. 中转站故障保持原提示词重试；内容安全拦截展示原词、新词和修改说明，并在付费重做前再次确认。
10. 本地 FFmpeg 合成、声音轨、字幕烧录、独立 SRT、7 项自动质检、人工清单和 MP4/SRT/报告/说明/ZIP 打包。

## 三、不可改变的产品规则

1. 禁止“一键直接成片”。剧本、分镜、资产、声音、逐镜视频和最终成片均保留人工审核关。
2. 每个审核关只让用户提交一次；后台自动保留提交、批准和锁定审计状态。
3. 能用单选、多选或勾选完成的问题，不要求用户手动输入。
4. 每一步必须在画布上可见：节点实时出现、状态可见、可中断、可恢复。
5. 失败只重做失败阶段或失败镜头；已完成节点和成功版本不得被删除或覆盖。
6. 审核不通过时必须联动对应提示词或上游输入，展示修改前后差异和影响范围，再由用户确认局部重做。
7. 图片、视频和大语言模型读取画布全局 API 配置；画布配置了什么模型，Agent 才能选择什么模型。
8. 一键复色与画布是独立系统：不共享素材、项目、任务、队列和结果；只共享软件主题与全局 API 配置能力。
9. 缺少真实依赖时必须阻塞，禁止伪造回执、伪造调研或伪造媒体结果。

## 四、恢复后的执行顺序

### 里程碑 A：完成正式阶段 9

1. 打开阶段 9.3 审核界面并恢复镜头 2 的失败状态。
2. 核对内容安全失败原因、原提示词、勾选式修改方向、修改后提示词和修改说明。
3. 用户确认修改内容与该镜头最低费用后，只重做镜头 2。
4. 播放并审核镜头 2；不满意时继续保留历史版本并局部重做。
5. 五个镜头全部通过后只提交一次，锁定完整阶段九视频包。

### 里程碑 B：完成正式阶段 10

1. 使用锁定且当前有效的阶段八声音包和阶段九完整视频包建立正式合成计划。
2. 核对镜头数量、顺序、时长、比例、分辨率、帧率和格式。
3. 执行本地合成、字幕、声音、自动质检和失败恢复。
4. 用户播放正式成片并勾选最终人工清单。
5. 只提交一次，锁定正式 MP4、SRT、质检报告、版本来源说明和 ZIP。

### 里程碑 C：真实品牌全流程回归

1. 使用已授权的真实测试品牌，从 Skill 卡片入口重新跑一条完整流程。
2. 图片测试使用低成本配置；视频使用最低可接受时长、分辨率和价格的模型。
3. 验证暂停、继续、取消、刷新、新窗口恢复、违规、超时、中转站失败和局部重做。
4. 验证每个审核关只提交一次，且不会越过人工审核直接成片。

### 里程碑 D：统一 UI 改造中的画布阶段

全软件 UI 改造是独立工作流。进入其“画布、Agent 与视频系统”阶段时，只统一字体、图标、颜色、主题令牌、按钮材质、状态灯和审核组件，不改变画布工具栏、节点位置、右栏宽度、10 阶段工作流、数据结构或业务行为。

## 五、验收标准

- 五个正式镜头全部可播放并通过人工审核，阶段九视频包已锁定。
- 正式阶段十只接受完整锁定输入，缺一个镜头时必须继续阻塞。
- 审核不通过能够联动提示词或上游输入，并明确显示影响范围与局部重做入口。
- 失败任务不会影响其他成功任务，也不会丢失历史版本。
- 刷新、服务重启或换窗口后，节点、选择、审核状态和唯一下一步能够恢复。
- 最终交付包中的 MP4、SRT、质检报告、版本来源说明和 ZIP 均可打开并对应同一锁定版本。
