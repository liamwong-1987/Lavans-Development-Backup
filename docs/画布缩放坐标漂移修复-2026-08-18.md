# 画布缩放坐标漂移修复

**日期**: 2026-08-18  
**文件**: `resources/frontend/smart-canvas-core/smart-canvas-core.js`（单文件，1 处改动）  

---

## 问题

图片编辑器缩放后，遮罩层/画笔绘制位置与鼠标指针位置发生偏移（坐标漂移）。

## 根因分析

之前为修复 CSS `zoom` 下的鼠标偏移，给 `editDrawPoint` 添加了 `offsetX/offsetY` 优先路径：

```js
// 旧代码（有问题的版本）
if(typeof event.offsetX === 'number' && typeof event.offsetY === 'number'){
    return {x:event.offsetX * canvasEl.width / cw, y:event.offsetY * canvasEl.height / ch};
}
```

`offsetX` 是元素自身布局坐标，虽不受父级 CSS `zoom` 影响，但在图片缩放（`imageEditZoom`）后，`canvasEl.style.width` 变化而 `canvasEl.width`（像素分辨率）不变，`offsetX` 与 `getBoundingClientRect` 产生的坐标映射不一致，导致画笔落点偏移。

## 对比参考仓库

逐函数对比大神仓库（`Infinite-Canvas/static/js/smart-canvas.js`）：

| 函数 | 当前代码 | 参考代码 | 结论 |
|------|---------|---------|------|
| `editDrawPoint` | offsetX + fallback | getBoundingClientRect | **不一致，需修复** |
| `resizeEditDrawCanvas` | 一致 | 一致 | OK |
| `cropImageDisplaySize` | 一致 | 一致 | OK |
| `applyImageEditZoom` | 一致 | 一致 | OK |
| `ensureImageEditBaseSize` | 一致 | 一致 | OK |
| `beginEditDraw` | 一致 | 一致 | OK |
| `moveEditDraw` | 一致 | 一致 | OK |

**唯一差异**：`editDrawPoint`。参考代码使用纯 `getBoundingClientRect` 版本，且运行稳定。

## 修复

还原为参考代码的 `getBoundingClientRect` 版本：

```js
function editDrawPoint(event){
    const canvasEl = editDrawCanvas();
    const rect = canvasEl.getBoundingClientRect();
    return {x:(event.clientX - rect.left) * canvasEl.width / Math.max(1, rect.width), y:(event.clientY - rect.top) * canvasEl.height / Math.max(1, rect.height)};
}
```

**原理**：
- `getBoundingClientRect()` 返回元素在视口中的视觉尺寸（含 CSS zoom/transform）
- `event.clientX` 是视口坐标
- `(event.clientX - rect.left) / rect.width` 归一化到视觉画布比例
- 乘以 `canvasEl.width`（像素分辨率）映射到画布像素坐标
- 无论图片缩放到任何倍数，坐标映射始终精准
