# Canvas AGENT 阶段 2：产品事实与调研实施计划

## 范围

- Task 2.1：保留问卷与上传资料的可读内容，生成资料清单、证据等级、冲突提示和产品事实锁。
- Task 2.2：只使用拥有合法使用权的本地故事数据库，执行健康检查及“题材/人物关系”“钩子/节奏/植入”两次离线检索；缺库时如实阻塞，不伪造结果。
- Task 2.3：生成调研边界，明确允许来源、禁止来源、禁说项、网络使用状态和进入阶段 3 的审核条件。

## 可见产物

1. 资料与证据
2. 产品事实锁
3. 离线调研结果或真实阻塞回执
4. 调研边界

以上产物均通过阶段 1 的不可变版本、依赖图与审核状态机投影到画布；用户逐项审核、批准和锁定后才允许阶段 3 使用。

## 安全边界

- 本阶段不调用图片、视频或外部文本模型。
- 本阶段不自动上网检索，不发送用户资料。
- 不修改一键复色的素材、配置、任务或 API。
- 缺少数据库、证据或用户确认时保留可见阻塞节点，不伪造完成。

## 测试

- 资料字段持久化、证据分级、冲突提示、禁说项和事实锁。
- 本地数据库正常/缺失/无效三类路径，确认 `network_used=false`。
- 四个画布节点、依赖关系、审核状态和刷新恢复。
- 旧 AGENT、剧本审核、阶段 1 底座与生产画布隔离回归。
