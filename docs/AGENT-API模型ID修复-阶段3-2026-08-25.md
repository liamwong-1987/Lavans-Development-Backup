# AGENT / API 模型 ID 修复：阶段 3 断点

## 目标

确保中转站返回的模型 ID 在拉取、保存、重启和真实提交链路中保持一致；仅移除明确的结构包装，不自动改名。

## 已确认规则

- 保存和提交使用上游返回的精确模型 ID。
- 不添加或删除 `doubao-` 等厂商前缀，不改大小写、斜杠、版本号或后缀。
- 仅允许拆除两种明确包装：JSON 字符串包装、只包含一个字符串的 JSON 数组包装。
- 展示名称继续保存在 `model_names`，不能替代请求 ID。
- 音频与未知模型列表必须能够保存并在重启归一化后保留。
- 本阶段不改前端分类 UI，不真实提交媒体，不修改 API Key。
