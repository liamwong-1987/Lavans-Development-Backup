# 视频节点显示比例修复

**日期**: 2026-08-18  
**文件**: `smart-canvas-core.css`（1 行）、`smart-canvas-core.js`（1 行）  

---

## 问题

API 生成视频（9:16 竖屏）在画布中显示时：
- 容器宽高比与视频实际比例不一致
- 画面被裁切或拉伸
- 即使在播放和缩放时比例也不对

## 根因

**后端**：`/api/media-preview` 对视频文件返回 415（`视频缩略图尚未接入`），不支持视频帧提取。

**前端**：`smartVideoPreviewHtml` 生成 `<img src="/api/media-preview?w=768&url=...">`，后端返回 415 → 图片加载失败 → `node.w`/`node.h` 在 `replaceOutputsToNodeWithHistory` 中被删除后从未重新设置 → 节点尺寸停留在经典节点默认值 400×470 → 与 9:16 比例（约 0.56）完全不匹配 → CSS `object-fit:cover` 进一步裁切。

## 修复

### 1. CSS（`smart-canvas-core.css` 第 662 行）

```css
/* 改前 */
object-fit:cover;
/* 改后 */
object-fit:contain;
```

禁止裁切/拉伸，视频始终按原始比例等比显示。

### 2. JS（`smart-canvas-core.js` 第 6927 行）

```js
// 改前：<img> 标签，预览 URL 后端返回 415
smartVideoPreviewHtml(img, 768, 'alt=""')

// 改后：<video preload="metadata"> 标签，浏览器加载视频元数据
smartVideoFallbackHtml(img.url || img, 'data-preview-kind="video"')
```

**效果**：`<video preload="metadata">` 只加载视频元数据（尺寸、时长），不加载完整视频。`loadedmetadata` 事件触发后：

1. `apply()` 从 `videoWidth`/`videoHeight` 获取真实尺寸
2. `singleImageLayout` 按 `maxW=520, maxH=440` 等比缩放（9:16 → 247×440）
3. `node.w`/`node.h` 更新为正确值
4. `updateNodeElementDuringResize` 同步卡片容器尺寸（已支持 `.node-img` 更新）
5. 视频以 `object-fit:contain` 在正确比例的容器中等比显示
