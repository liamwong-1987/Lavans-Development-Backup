# 智能画布三 BUG 修复报告

**日期**：2026-08-18
**模块**：智能画布（smart-canvas-core.js）
**性质**：Bug 修复（单文件，3 处）

---

## 一、BUG 清单与根因

| # | 症状 | 根因 | 修复 |
|---|------|------|------|
| 1 | API 生成节点 PROMPT 放大后 @ 不了图片 | 放大走 `expandSmartPromptEditor`，用 `textContent` 复制内容（丢失 @ 提及 HTML），且不移动 `mentionPicker` | 改为先同步到 composer，再走 `expandComposerPrompt`（innerHTML + 移动 picker） |
| 2 | Ctrl+Shift+Z 无法恢复上一步 | 只有 `undoStack` 没有 `redoStack`，撤销后当前状态直接丢弃 | 新增 `redoStack` + `performRedo`，撤销前保存当前状态 |
| 3 | 遮罩/画笔鼠标位置偏移非常大 | `editDrawPoint` 用 `clientX/getBoundingClientRect`（视觉坐标）映射，画布尺寸用 `clientWidth`（布局坐标），CSS `zoom` 缩放时两者不一致 | 改用 `offsetX/offsetY`（相对画布自身布局坐标） |

## 二、改动明细

### Bug 1：PROMPT 放大 @ 提及

`handleSmartPromptExpandPointer()`（约 L19454）：
```js
// 原：expandSmartPromptEditor(control, ...)
// 改：把节点 PROMPT 同步到 composer，再打开全屏（保留 @ 提及 HTML）
if(promptInput && control){
    promptInput.innerHTML = (control.value || control.innerText || '').replace(/\n/g, '<br>');
    expandComposerPrompt();
} else {
    expandSmartPromptEditor(control, expand.dataset.promptExpandTitle || 'PROMPT');
}
```

`expandComposerPrompt` 使用 `innerHTML` 复制、移动 `mentionPicker`、调用 `bindSmartPreviewImageFallbacks`，@ 提及功能完整恢复。

### Bug 2：Ctrl+Shift+Z 重做

- 新增 `const redoStack = []`
- `performUndo()`：撤销前 `redoStack.push(snapshotForUndo())` 保存当前状态
- 新增 `performRedo()`：对称实现，`undoStack.push` 当前状态后恢复 redo 快照
- Ctrl+Z 处理：`e.shiftKey ? performRedo() : performUndo()`
- `pushUndo()` / `commitPendingUndo()`：`redoStack.length = 0`（新编辑后重做历史作废）

### Bug 3：画笔/遮罩鼠标偏移

`editDrawPoint()`（约 L12128）：
```js
function editDrawPoint(event){
    const canvasEl = editDrawCanvas();
    const cw = Math.max(1, canvasEl.clientWidth);
    const ch = Math.max(1, canvasEl.clientHeight);
    // 优先 offsetX/offsetY：相对画布自身布局坐标，规避 zoom/transform 偏移
    if(typeof event.offsetX === 'number' && typeof event.offsetY === 'number'){
        return {x:event.offsetX * canvasEl.width / cw, y:event.offsetY * canvasEl.height / ch};
    }
    const rect = canvasEl.getBoundingClientRect();
    return {x:(event.clientX - rect.left) * canvasEl.width / Math.max(1, rect.width), ...};
}
```

## 四、已知限制

- Bug 3（鼠标偏移）采用 `offsetX/offsetY` 修复，规避了 CSS `zoom` 的坐标不一致；但实际效果需在浏览器中验证缩放场景下画笔落点是否与鼠标对齐。建议用户在缩放界面（非 100% 缩放）下测试遮罩/画笔。
